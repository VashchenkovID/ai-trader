## 🐛 Решение проблем

### Проблема: Сервер не запускается

**Возможные причины:**
1. Порт занят → Изменить `PORT` в `.env`
2. Ошибка подключения к БД → Проверить настройки БД
3. Отсутствуют зависимости → `npm install`

**Решение:**
```bash
# Проверить занятость порта
netstat -ano | findstr :3001

# Проверить подключение к БД
psql -h localhost -U postgres -d smart_exchange
```

### Проблема: Клиент не подключается к серверу

**Возможные причины:**
1. Сервер не запущен
2. Неправильный URL в `apiService.ts`
3. CORS ошибки

**Решение:**
- Проверить, что сервер запущен на порту 3001
- Проверить настройки CORS в `server/src/app.js`
- Проверить `API_BASE_URL` в `client/src/services/apiService.ts`

### Проблема: WebSocket не подключается

**Возможные причины:**
1. WebSocketService не инициализирован
2. Проблемы с проксированием

**Решение:**
- Проверить логи сервера при запуске
- Проверить настройки прокси в `vite.config.ts`
- Проверить, что WebSocketService инициализирован в ServiceManager

### Проблема: Страница не загружается

**Возможные причины:**
1. Ошибки компиляции TypeScript
2. Отсутствующие зависимости
3. Проблемы с роутингом

**Решение:**
```bash
# Проверить ошибки компиляции
cd client
npm run build

# Проверить линтер
npm run lint
```
