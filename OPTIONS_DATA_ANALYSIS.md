# Анализ эффективности опционных данных для обучения нейросетей

## Текущее состояние системы

### Текущий размер feature vector: **38 фичей**
- **5 фичей**: Нормализованные цены (close, high, low, open, средняя)
- **5 фичей**: Нормализованные объемы (последние 5 свечей)
- **6 фичей**: Технические индикаторы (RSI, MACD, Bollinger Bands, SMA, EMA, ATR)
- **2 фичи**: Временные (день недели, час)
- **3 фичи**: Рыночные (индекс, корреляция, волатильность рынка)
- **2 фичи**: Новостные (количество, настроение)
- **2 фичи**: Telegram (настроение, активность)
- **5 фичей**: Сигналы аналитиков
- **8 фичей**: Макроэкономические (ключевая ставка, инфляция, ВВП и т.д.)

## Предлагаемые опционные фичи

### 1. Implied Volatility (IV) - Подразумеваемая волатильность

**Что это:**
- Ожидаемая волатильность, заложенная в цене опциона
- Вычисляется из цены опциона через модель Блэка-Шоулза
- Отражает рыночные ожидания относительно будущей волатильности

**Потенциальная эффективность: ⭐⭐⭐⭐⭐ (5/5)**

**Преимущества:**
- ✅ **Высокая информативность**: IV - это "страхометр" рынка, показывает ожидания инвесторов
- ✅ **Опережающий индикатор**: Обычно опережает реальную волатильность на 1-2 недели
- ✅ **Уникальная информация**: Не дублирует существующие фичи (ATR показывает историческую волатильность, IV - ожидаемую)
- ✅ **Корреляция с движением цены**: Высокая IV часто предшествует большим движениям
- ✅ **Используется в профессиональной торговле**: HFT и институциональные трейдеры активно используют IV

**Ограничения:**
- ⚠️ **Доступность данных**: Не все инструменты имеют опционы (только ликвидные акции)
- ⚠️ **Качество данных**: Нужна модель Блэка-Шоулза для вычисления IV из цены опциона
- ⚠️ **Задержка обновления**: Данные могут обновляться не так часто, как свечи

**Рекомендация:** ✅ **ВЫСОКАЯ ПРИОРИТЕТНОСТЬ**

**Реализация:**
- Добавить 2-3 фичи: IV текущая, IV средняя за период, IV rank (процентиль)
- Размер feature vector: 38 → 41 (+3 фичи)

---

### 2. Put/Call Ratio - Соотношение пут/колл опционов

**Что это:**
- Отношение объема/открытого интереса пут-опционов к колл-опционам
- Показывает настроения инвесторов (медвежьи vs бычьи)

**Потенциальная эффективность: ⭐⭐⭐⭐ (4/5)**

**Преимущества:**
- ✅ **Индикатор настроений**: Высокий PCR (>1.0) = медвежье настроение, низкий (<0.7) = бычье
- ✅ **Контрарный индикатор**: Экстремальные значения часто предшествуют разворотам
- ✅ **Дополняет существующие фичи**: Telegram и новости показывают текстовые настроения, PCR - реальные действия инвесторов
- ✅ **Используется в практике**: Многие трейдеры следят за PCR

**Ограничения:**
- ⚠️ **Не всегда надежен**: Может быть искажен хеджированием и арбитражем
- ⚠️ **Нужна нормализация**: Разные инструменты имеют разные базовые уровни PCR
- ⚠️ **Зависит от ликвидности**: Для неликвидных инструментов может быть неточным

**Рекомендация:** ✅ **СРЕДНЯЯ ПРИОРИТЕТНОСТЬ**

**Реализация:**
- Добавить 1-2 фичи: PCR текущий, PCR средний за период
- Размер feature vector: 38 → 40 (+2 фичи)

---

### 3. Open Interest (OI) - Открытый интерес

**Что это:**
- Количество открытых контрактов по опционам
- Показывает активность и интерес к инструменту

**Потенциальная эффективность: ⭐⭐⭐ (3/5)**

**Преимущества:**
- ✅ **Индикатор интереса**: Высокий OI = высокий интерес к инструменту
- ✅ **Может предсказывать объемы**: Рост OI часто предшествует росту объемов торговли
- ✅ **Дополнительный контекст**: Показывает, насколько активно торгуются опционы

**Ограничения:**
- ⚠️ **Низкая информативность**: OI сам по себе не очень предсказателен
- ⚠️ **Дублирует информацию**: Объемы торговли уже есть в фичах
- ⚠️ **Нужна нормализация**: Абсолютные значения OI не информативны, нужны относительные

**Рекомендация:** ⚠️ **НИЗКАЯ ПРИОРИТЕТНОСТЬ**

**Реализация:**
- Можно добавить как дополнительную фичу, но не критично
- Размер feature vector: 38 → 39 (+1 фича)

## План реализации

### Фаза 1: Implied Volatility (MVP)
- Интеграция с Tinkoff API для получения опционов
- Вычисление IV из цен опционов (модель Блэка-Шоулза)
- Добавление IV фичей в `OptimizedDataService`
- Тестирование на исторических данных

**Ожидаемый результат:** +3-5% точности

### Фаза 2: Put/Call Ratio
- Вычисление PCR из данных опционов
- Нормализация PCR для разных инструментов
- Добавление PCR фичей

**Ожидаемый результат:** +1-2% точности

### Фаза 3: Open Interest (опционально)
- Сбор данных OI
- Нормализация OI
- Добавление OI фичей

**Ожидаемый результат:** +0.5-1% точности

## Альтернативные подходы

### Если опционы недоступны для большинства инструментов:

1. **Использовать только для ликвидных акций**
   - Применять опционные фичи только для инструментов с достаточной ликвидностью опционов
   - Для остальных использовать нулевые значения или средние по рынку

2. **Использовать VIX-подобные индексы**
   - Если доступны индексы волатильности (аналог VIX для российского рынка)
   - Можно использовать как прокси для IV

3. **Вычислять "синтетическую" IV**
   - Использовать историческую волатильность + корректировку на основе настроений
   - Менее точно, но доступно для всех инструментов
