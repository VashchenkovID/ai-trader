## 📊 Структура данных PnL

Все API endpoints и WebSocket сообщения используют новую структуру:
- `pnl.total` - общая прибыль/убыток
- `pnl.totalPercent` - процент от скорректированного капитала
- `pnl.realized` - реализованная прибыль
- `pnl.realizedPercent` - процент реализованной прибыли
- `pnl.unrealized` - нереализованная прибыль
- `pnl.winRate` - процент прибыльных сделок
- `pnl.totalTrades` - общее количество сделок

**Старые поля `totalPnL` и `totalPnLPercent` удалены.**
