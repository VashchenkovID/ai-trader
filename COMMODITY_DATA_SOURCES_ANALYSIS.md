# Анализ источников данных о ценах на сырье (нефть Brent, газ, металлы)

## Требуемые данные

1. **Нефть Brent** (международный эталон)
2. **Газ** (природный газ, российский рынок)
3. **Металлы** (золото, серебро, медь, никель, алюминий)

## Доступные источники данных

### 1. MOEX ISS API (Мосбиржа) ⭐ РЕКОМЕНДУЕТСЯ

**Преимущества:**
- ✅ Официальный API Мосбиржи (ISS - Information & Statistical Server)
- ✅ Бесплатный доступ
- ✅ Стабильный и надежный
- ✅ Ежедневные обновления
- ✅ Исторические данные доступны
- ✅ Подходит для российского рынка (газ, металлы)

**Доступные инструменты:**
- Нефть: фьючерсы на нефть Urals (BR)
- Газ: фьючерсы на природный газ (NG)
- Золото: фьючерсы (GD)
- Серебро: фьючерсы (SV)
- Медь: фьючерсы (CU)
- Никель: фьючерсы (NI)
- Алюминий: фьючерсы (AL)

**API Endpoints:**
- `https://iss.moex.com/iss/history/engines/futures/markets/forts/securities/{secid}.json` - исторические данные по инструменту
- `https://iss.moex.com/iss/engines/futures/markets/forts/securities/{secid}.json` - текущие данные
- `https://iss.moex.com/iss/engines/futures/markets/forts/boards/{board}/securities/{secid}.json` - данные по конкретному борту

**Пример запроса:**
```
GET https://iss.moex.com/iss/history/engines/futures/markets/forts/securities/BR-1.24.json?from=2024-01-01&till=2024-12-31
```

**Ограничения:**
- ⚠️ Нефть Brent (международный эталон) может отсутствовать, есть только Urals
- ⚠️ Нужно отслеживать истекающие фьючерсы (месячные контракты)

### 2. Tinkoff Invest API

**Преимущества:**
- ✅ Уже используется в проекте
- ✅ Есть доступ к инструментам Мосбиржи
- ✅ Можно получить данные через getInstrumentBy, getLastPrices

**Ограничения:**
- ⚠️ Нужно знать FIGI инструментов
- ⚠️ Может не покрывать все нужные инструменты на сырье
- ⚠️ Ограничения по лимитам запросов

**Подход:**
- Найти FIGI фьючерсов на сырье через поиск инструментов
- Использовать getLastPrices для текущих цен
- Использовать getCandles для исторических данных

### 3. Investing.com (парсинг HTML) ❌ НЕ РЕКОМЕНДУЕТСЯ

**Преимущества:**
- ✅ Широкий охват инструментов
- ✅ Международные данные (Brent)

**Недостатки:**
- ❌ Парсинг HTML - нестабильно
- ❌ Может нарушать ToS
- ❌ Требует регулярного обновления парсера
- ❌ Риск блокировок

### 4. Alpha Vantage API

**Преимущества:**
- ✅ Надежный API
- ✅ Международные данные
- ✅ JSON формат

**Недостатки:**
- ❌ Платный для коммерческого использования
- ❌ Ограничения по запросам на бесплатном плане

### 5. Yahoo Finance API (yfinance)

**Преимущества:**
- ✅ Бесплатный
- ✅ Международные данные
- ✅ Хорошее покрытие

**Недостатки:**
- ⚠️ Неофициальный API (может быть нестабильным)
- ⚠️ Может требовать парсинг HTML
- ⚠️ Риск изменения формата

## Рекомендуемое решение

### Приоритет 1: MOEX ISS API (для российских инструментов)

Для российского рынка (газ, металлы, нефть Urals) используем MOEX ISS API:

1. **Инструменты:**
   - Газ: фьючерсы NG (природный газ)
   - Золото: фьючерсы GD
   - Серебро: фьючерсы SV
   - Медь: фьючерсы CU
   - Никель: фьючерсы NI
   - Алюминий: фьючерсы AL
   - Нефть: фьючерсы BR (Urals)

2. **Реализация:**
   - Создать новый метод `fetchMoexCommodityData()` в `MacroDataService`
   - Парсить JSON ответы от MOEX ISS API
   - Сохранять в `MacroIndicator` с типом `commodity_price`
   - Использовать `metadata` для хранения типа сырья (gas, gold, silver, copper, nickel, aluminum, oil)

### Приоритет 2: Tinkoff API (как дополнение)

Использовать для получения FIGI инструментов и как альтернативный источник:

1. Найти FIGI фьючерсов на сырье
2. Использовать `getLastPrices` для текущих цен
3. Использовать `CacheService.getCandles` для исторических данных (если доступно)

### Приоритет 3: Альтернатива для Brent (международный)

Для нефти Brent (международный эталон) можно рассмотреть:
- Использовать Yahoo Finance API через неофициальную библиотеку (если необходимо)
- Или использовать данные MOEX по Urals как прокси для Brent

## Структура данных

### MacroIndicator
- `indicatorType`: `'commodity_price'` (новый тип)
- `source`: `'moex_iss'` или `'tinkoff'`
- `value`: цена (в USD или RUB в зависимости от инструмента)
- `period`: дата
- `periodType`: `'daily'` (ежедневные данные)
- `unit`: `'absolute'` (абсолютное значение цены)
- `metadata`: 
  ```json
  {
    "commodityType": "oil" | "gas" | "gold" | "silver" | "copper" | "nickel" | "aluminum",
    "commodityCode": "BR" | "NG" | "GD" | "SV" | "CU" | "NI" | "AL",
    "futuresContract": "BR-1.24",
    "currency": "RUB" | "USD",
    "previousValue": 85.5,
    "change": 1.2,
    "changePercent": 1.42
  }
  ```

## План реализации

1. Добавить новый тип `'commodity_price'` в ENUM `indicatorType` модели `MacroIndicator`
2. Создать парсер для MOEX ISS API в `macroDataParsers.js`
3. Добавить метод `fetchMoexCommodityData()` в `MacroDataService`
4. Обновить `getMacroFeatures()` для включения цен на сырье
5. Добавить cron job для ежедневного обновления данных
6. Протестировать на реальных данных

## Альтернативные варианты (если MOEX ISS API не подходит)

Если MOEX ISS API будет слишком сложным в использовании или недоступным:

1. **Использовать только Tinkoff API:**
   - Найти FIGI фьючерсов через поиск
   - Использовать существующую инфраструктуру CacheService
   - Хранить данные в MacroIndicator

2. **Комбинированный подход:**
   - MOEX ISS API для российских инструментов (газ, металлы)
   - Tinkoff API как fallback
   - Для Brent использовать Urals как прокси
