## Запуск тестов


```bash
cd server
node test-pnl-calculation.js
```

## Проверенные сценарии

### 1. Расчет прибыли от одной сделки
- Вход: entryPrice=100, exitPrice=110, quantity=10, commission=5
- Ожидаемый результат: PnL = 95
- ✅ Тест пройден

### 2. Расчет убытка от одной сделки
- Вход: entryPrice=100, exitPrice=90, quantity=10, commission=5
- Ожидаемый результат: PnL = -105
- ✅ Тест пройден

### 3. Множественные сделки
- Вход: 3 сделки (2 прибыльные, 1 убыточная)
- Ожидаемый результат: Total PnL = 90, Win Rate = 66.67%
- ✅ Тест пройден

### 4. Нереализованная прибыль
- Вход: entryPrice=100, currentPrice=110, quantity=10
- Ожидаемый результат: Unrealized PnL = 100
- ✅ Тест пройден

### 5. CashFlow операции
- Вход: Депозиты 500k + 300k, Вывод 200k
- Ожидаемый результат: Net Cash Flow = 600k
- ✅ Тест пройден

### 6. Полный расчет с CashFlow
- Вход: Initial Capital = 1M, Deposits = 500k, Realized PnL = 95, Unrealized PnL = 50
- Ожидаемый результат: Adjusted Capital = 1.5M, Total PnL = 145
- ✅ Тест пройден

## Известные ограничения

1. **HTTP тесты** - требуют установки `supertest` для полного тестирования endpoints
2. **Интеграционные тесты** - требуют настроенной тестовой БД
3. **Ручной тест** - может не работать без настроенной БД (но это нормально)
