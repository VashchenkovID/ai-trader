## 📝 История изменений

### Версия 1.4 (2025-01-28)
- ✅ Оптимизация входов и выходов из позиций:
  - Создан `EntryOptimizationService` для оптимизации входов:
    - Проверка индикаторов (RSI, MACD, Bollinger Bands) для подтверждения сигнала
    - Ожидание коррекции для лучшей цены входа
    - Использование лимитных ордеров вместо рыночных (0.5% лучше текущей цены)
    - Проверка объема торгов перед входом (минимум 80% от среднего)
    - Требуется минимум 2 подтверждающих индикатора
    - Интеграция в `TradingRequestService` при создании заявок
    - Сохранение информации об оптимизации в поле `entryOptimization` модели `TradingRequest`
  - Создан `ExitOptimizationService` для оптимизации выходов:
    - Выход при изменении фундаментальных факторов (изменение score на 15%+)
    - Выход при достижении временного горизонта стратегии (предупреждение за 7 дней)
    - Выход при снижении confidence ниже порога (50%) или падении на 20% от исходной
    - Учет налоговых последствий (ИИС, долгосрочные позиции > 3 лет)
    - Анализ изменения рекомендации AI (BUY→SELL, SELL→BUY)
    - Проверка близости к стоп-лоссу (предупреждение при 2% до стоп-лосса)
  - API endpoints для тестирования:
    - `POST /api/trading-requests/test-entry-optimization` - тестирование анализа входа
    - `POST /api/trading-requests/test-exit-optimization` - тестирование анализа выхода
  - Миграция для добавления столбца `entryOptimization` в таблицу `trading_requests`
  - Все тесты пройдены успешно
