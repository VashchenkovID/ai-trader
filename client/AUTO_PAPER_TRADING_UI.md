# Интерфейс автоматической торговли

## Где найти

Автоматическая торговля доступна в настройках:
1. Перейдите в **Настройки** (Settings)
2. Откройте вкладку **"Режимы торговли"**
3. Переключитесь на режим **"📄 Бумажная торговля" (paper)**
4. Внизу карточки режима появится секция **"🤖 Автоматическая торговля"**

## Функционал

### Статус
- **Включена/Выключена** - текущее состояние автоматической торговли
- **Фаза** - текущая фаза работы (Фаза 1, 2 или 3)

### Статистика
- **Сделок сегодня** - количество сделок за сегодня и лимит
- **PnL сегодня** - прибыль/убыток за сегодня
- **Всего сделок** - общее количество сделок
- **Прогресс дневных сделок** - визуальный индикатор использования лимита

### Настройки
Отображаются текущие настройки:
- Min Confidence (минимальная уверенность)
- Max Position Size (максимальный размер позиции)
- Max Daily Loss (максимальный дневной убыток)

### Действия

1. **Включить/Выключить автоматическую торговлю**
   - Кнопка переключает состояние автоматической торговли
   - При включении обрабатываются все свежие заявки (созданные в последние 4 часа)

2. **Перейти на следующую фазу**
   - Доступно только если текущая фаза не последняя (phase3)
   - Требует подтверждения
   - Доступно только когда автоматическая торговля включена

3. **Обновить статус**
   - Ручное обновление данных
   - Автоматическое обновление происходит каждые 30 секунд

### Предупреждения

Компонент показывает предупреждения:
- При приближении к лимиту дневных сделок (80%+)
- При приближении к лимиту дневного убытка (80%+)
- Если сервис не инициализирован

## Технические детали

### Компоненты
- `AutoPaperTradingSection.tsx` - основной компонент управления
- `autoPaperTradingService.ts` - сервис для работы с API

### API Endpoints
- `GET /api/auto-paper-trading/status` - получение статуса
- `POST /api/auto-paper-trading/enable` - включение
- `POST /api/auto-paper-trading/disable` - выключение
- `GET /api/auto-paper-trading/stats` - статистика
- `PUT /api/auto-paper-trading/settings` - обновление настроек
- `POST /api/auto-paper-trading/advance-phase` - переход на следующую фазу

### Условия работы

Автоматическая торговля работает только когда:
1. ✅ Режим торговли: `paper`
2. ✅ Автоматическая торговля включена
3. ✅ Сервис инициализирован
4. ✅ Заявки соответствуют критериям (confidence, лимиты и т.д.)
