# План редизайна и рефакторинга детальной страницы акции

## 📋 Цель
Создать максимально интуитивно понятную страницу детальной информации об акции с использованием новой дизайн-системы и улучшенным UX.

## 🎯 Принципы редизайна

### 1. Интуитивность
- **Приоритет информации**: Самые важные данные (цена, рекомендация, действия) должны быть видны сразу
- **Визуальная иерархия**: Четкое разделение на секции с понятными заголовками
- **Понятные метрики**: Замена технических терминов на простые объяснения
- **Визуальные индикаторы**: Использование цветов, иконок и бейджей для быстрого понимания

### 2. Производительность
- **Ленивая загрузка**: Загружать данные по мере необходимости
- **Оптимизация графиков**: Использовать эффективные библиотеки
- **Кэширование**: Кэшировать часто запрашиваемые данные

### 3. Адаптивность
- **Мобильная версия**: Полностью адаптивный дизайн
- **Таблицы**: Преобразование в карточки на мобильных устройствах
- **Графики**: Адаптивные размеры и интерактивность

## 📐 Структура страницы

### Верхняя секция (Hero Section)
```
┌─────────────────────────────────────────────────────────┐
│  ← Назад    [Название акции] (TICKER)                   │
│                                                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 💰 Цена: 1,234.56 ₽  [↑ 2.5%]  [Обновлено: ...] │  │
│  │ 📊 Рекомендация: Покупать  [Уверенность: 85%]   │  │
│  │ 🎯 Целевая цена: 1,300 ₽  [Потенциал: +5.3%]     │  │
│  │ ⚠️ Стоп-лосс: 1,200 ₽  [Риск: -2.8%]            │  │
│  └──────────────────────────────────────────────────┘  │
│                                                          │
│  [💰 Купить]  [📊 Анализ]  [🎓 Обучить]                │
└─────────────────────────────────────────────────────────┘
```

### Основной контент (2 колонки на десктопе, 1 на мобильном)

#### Левая колонка (8/12 на десктопе)
1. **График цены** (интерактивный, с переключением периодов)
2. **График объема торгов**
3. **История предсказаний** (график + таблица)

#### Правая колонка (4/12 на десктопе)
1. **Прогнозы по горизонтам** (карточки)
2. **Торговые сигналы** (список)
3. **Новости** (список)

## 🎨 Дизайн-решения

### Цветовая схема
- **Цена роста**: Зеленый градиент
- **Цена падения**: Красный градиент
- **BUY рекомендация**: Зеленый
- **SELL рекомендация**: Красный
- **HOLD рекомендация**: Синий/Серый

### Типографика
- **Заголовок страницы**: Крупный, жирный
- **Цена**: Очень крупный шрифт (2xl-3xl)
- **Метрики**: Средний размер с четкой иерархией
- **Вспомогательный текст**: Мелкий, приглушенный цвет

### Иконки
- 💰 Цена
- 📊 Анализ/Рекомендация
- 🎯 Целевая цена
- ⚠️ Стоп-лосс
- 📈 График
- ⚡ Сигналы
- 📰 Новости
- 🎓 Обучение

### Анимации
- Плавное появление секций
- Анимация изменения цены
- Hover эффекты на карточках
- Плавные переходы между периодами графиков
