# Настройка генерации и обновления предсказаний

## Обзор

Система настроена для автоматической генерации и обновления предсказаний с целью повышения точности моделей через обучение на реальных данных.

## Расписание задач

### 1. Генерация прогнозов (ежедневно в 8:00)

**Задача:** `weeklyForecastGenerationTask`

**Расписание:** `'0 8 * * *'` (каждый день в 8:00)

**Что делает:**
- Генерирует недельные прогнозы для всех активных инструментов
- Проверяет наличие свежих прогнозов (не старше 24 часов) и пропускает их
- Использует исторические данные за 90 дней
- Включает макроэкономические данные и новости

**Настройка:**
Расписание можно изменить через настройку `weekly_forecast_generation_schedule` в таблице `settings`.

### 2. Обновление прогнозов реальными данными (ежедневно в 9:00)

**Задача:** `weeklyForecastUpdateTask`

**Расписание:** `'0 9 * * *'` (каждый день в 9:00, после генерации)

**Что делает:**
- Обновляет активные прогнозы реальными данными из рынка
- Вычисляет метрики точности (MAE, MSE, RMSE, MAPE, точность направления)
- Помечает завершенные прогнозы (после 7 дней)
- Автоматически запускает адаптивное обучение для завершенных прогнозов

**Настройка:**
Расписание можно изменить через настройку `weekly_forecast_update_schedule` в таблице `settings`.

### 3. Обучение моделей (еженедельно, понедельник в 4:00)

**Задача:** `weeklyForecastTrainingTask`

**Расписание:** `'0 4 * * 1'` (каждый понедельник в 4:00)

**Что делает:**
- Полное переобучение моделей Weekly Forecast для всех инструментов
- Использует исторические данные за 365 дней
- Обучает модели на 60 днях истории для прогноза на 7 дней вперед

**Настройка:**
Расписание можно изменить через настройку `weekly_forecast_training_schedule` в таблице `settings`.

## Адаптивное обучение

После завершения прогноза (через 7 дней) система автоматически:

1. **Сравнивает прогноз с реальностью** - вычисляет метрики точности
2. **Запускает адаптивное обучение** - дообучает модель на реальных данных
3. **Сохраняет новую версию модели** - с метаданными о предыдущей версии и метриках

Это позволяет моделям постоянно улучшаться на основе реальных результатов.

## Метрики точности

Система отслеживает следующие метрики:

- **MAE (Mean Absolute Error)** - средняя абсолютная ошибка
- **MSE (Mean Squared Error)** - средняя квадратичная ошибка
- **RMSE (Root Mean Squared Error)** - корень из средней квадратичной ошибки
- **MAPE (Mean Absolute Percentage Error)** - средняя абсолютная процентная ошибка
- **Direction Accuracy** - точность предсказания направления движения цены
- **Price Error** - ошибка в предсказании цены
- **Volume Error** - ошибка в предсказании объема

## Мониторинг

Все задачи регистрируются в `WorkerMonitoringService` и доступны для мониторинга через:

- API endpoint `/api/scheduler/status`
- WebSocket уведомления о прогрессе
- Логи в `LoggerService`

## Настройка через базу данных

Расписания можно изменить через таблицу `settings`:

```sql
-- Изменить расписание генерации прогнозов
UPDATE settings SET value = '0 7 * * *' WHERE key = 'weekly_forecast_generation_schedule';

-- Изменить расписание обновления прогнозов
UPDATE settings SET value = '0 10 * * *' WHERE key = 'weekly_forecast_update_schedule';

-- Изменить расписание обучения моделей
UPDATE settings SET value = '0 3 * * 1' WHERE key = 'weekly_forecast_training_schedule';
```

## Рекомендации

1. **Генерация прогнозов** должна выполняться до открытия торгов (8:00)
2. **Обновление прогнозов** должно выполняться после закрытия торгов предыдущего дня (9:00)
3. **Обучение моделей** лучше выполнять в выходные дни (понедельник в 4:00), когда нагрузка на систему минимальна

## Проверка работы

Для проверки работы задач можно использовать:

```bash
# Проверить статус задач
curl http://localhost:3000/api/scheduler/status

# Или через API
GET /api/scheduler/status
```

В ответе будут показаны статусы всех задач, включая:
- `weeklyForecastGenerationTask`
- `weeklyForecastUpdateTask`
- `weeklyForecastTrainingTask`
