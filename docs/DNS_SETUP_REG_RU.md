# 🌐 Настройка DNS записей в Reg.ru

Пошаговая инструкция по настройке DNS записей для домена в панели управления Reg.ru.

**IP адрес сервера:** `217.114.3.127`  
**DNS серверы:** `ns1.reg.ru`, `ns2.reg.ru`

---

## 📋 Шаг 1: Вход в панель управления Reg.ru

1. Откройте сайт: https://www.reg.ru/
2. Нажмите кнопку **"Войти"** в правом верхнем углу
3. Введите ваш логин и пароль
4. Нажмите **"Войти"**

---

## 📋 Шаг 2: Переход к управлению доменом

1. После входа вы попадете в **"Панель управления"**
2. В левом меню найдите раздел **"Домены"** или **"Мои домены"**
3. Нажмите на него
4. Найдите ваш домен в списке и нажмите на него

---

## 📋 Шаг 3: Проверка DNS серверов

1. В карточке домена найдите раздел **"DNS серверы"** или **"NS-серверы"**
2. Убедитесь, что указаны:
   - `ns1.reg.ru`
   - `ns2.reg.ru`

**Если DNS серверы другие:**
1. Нажмите **"Изменить"** или **"Редактировать"**
2. Выберите **"Стандартные DNS серверы Reg.ru"** или введите вручную:
   - `ns1.reg.ru`
   - `ns2.reg.ru`
3. Нажмите **"Сохранить"**

**Важно:** Изменение DNS серверов может занять до 24 часов для распространения.

---

## 📋 Шаг 4: Переход к управлению DNS записями

1. В карточке домена найдите раздел **"DNS-зона"** или **"Управление DNS"**
2. Нажмите на **"Управлять DNS-зоной"** или **"Редактировать DNS-зону"**

---

## 📋 Шаг 5: Настройка A записей

Вам нужно добавить или изменить две A записи:

### Запись 1: Основной домен (@)

1. Найдите существующую запись типа **A** с именем **@** (или пустым именем)
2. Если записи нет, нажмите **"Добавить запись"** или **"Создать запись"**
3. Заполните поля:
   - **Тип записи:** `A`
   - **Имя/Поддомен:** `@` (или оставьте пустым)
   - **Значение/IP адрес:** `217.114.3.127`
   - **TTL:** `3600` (или оставьте по умолчанию)
4. Нажмите **"Сохранить"** или **"Добавить"**

### Запись 2: Поддомен www

1. Найдите существующую запись типа **A** с именем **www**
2. Если записи нет, нажмите **"Добавить запись"** или **"Создать запись"**
3. Заполните поля:
   - **Тип записи:** `A`
   - **Имя/Поддомен:** `www`
   - **Значение/IP адрес:** `217.114.3.127`
   - **TTL:** `3600` (или оставьте по умолчанию)
4. Нажмите **"Сохранить"** или **"Добавить"**

---

## 📋 Шаг 6: Проверка записей

После добавления записей вы должны увидеть в списке DNS записей:

```
Тип    Имя    Значение              TTL
A      @      217.114.3.127         3600
A      www    217.114.3.127         3600
```

---

## 📋 Шаг 7: Проверка распространения DNS

После настройки DNS записей нужно подождать их распространения (обычно 5-30 минут, но может занять до 24 часов).

### Проверка через командную строку (Windows):

```powershell
# Проверка основной записи
nslookup yourdomain.com

# Проверка www поддомена
nslookup www.yourdomain.com
```

### Проверка через командную строку (Linux/Mac):

```bash
# Проверка основной записи
dig yourdomain.com +short

# Проверка www поддомена
dig www.yourdomain.com +short
```

**Ожидаемый результат:** `217.114.3.127`

### Онлайн проверка:

1. Откройте: https://dnschecker.org/
2. Введите ваш домен (например: `yourdomain.com`)
3. Выберите тип записи: `A`
4. Нажмите **"Search"**
5. Убедитесь, что во всех локациях отображается IP: `217.114.3.127`

---

## 🔧 Альтернативный способ: Через API Reg.ru

Если у вас есть доступ к API Reg.ru, можно настроить DNS записи программно:

```bash
# Пример через curl (требуется API ключ)
curl -X POST "https://api.reg.ru/api/regru2/zone/add_record" \
  -d "username=YOUR_USERNAME" \
  -d "password=YOUR_PASSWORD" \
  -d "domainname=yourdomain.com" \
  -d "subdomain=@" \
  -d "type=A" \
  -d "content=217.114.3.127"
```

**Примечание:** Для использования API нужен API ключ, который можно получить в панели управления Reg.ru.

## ⚠️ Важные замечания

1. **Время распространения:** Изменения DNS записей могут занять от 5 минут до 24 часов. Обычно это занимает 15-30 минут.

2. **Кеширование DNS:** Ваш компьютер и браузер могут кешировать старые DNS записи. Если изменения не видны:
   - Очистите кеш DNS: `ipconfig /flushdns` (Windows) или `sudo systemd-resolve --flush-caches` (Linux)
   - Используйте приватный режим браузера
   - Попробуйте другой DNS сервер (например, 8.8.8.8 от Google)

3. **Проверка перед получением SSL:** Обязательно убедитесь, что DNS записи распространились перед получением SSL сертификата через Let's Encrypt, иначе сертификат не будет выдан.

4. **Удаление старых записей:** Если у вас были другие A записи, их можно удалить или оставить (они не будут использоваться, если новые записи имеют приоритет).

## 🐛 Решение проблем

### Проблема: DNS записи не обновляются

**Решение:**
1. Проверьте, что DNS серверы домена действительно `ns1.reg.ru` и `ns2.reg.ru`
2. Убедитесь, что записи сохранены в панели Reg.ru
3. Подождите больше времени (до 24 часов)
4. Проверьте через разные DNS серверы (8.8.8.8, 1.1.1.1)

### Проблема: Не могу найти раздел DNS-зона

**Решение:**
1. Убедитесь, что домен действительно зарегистрирован в Reg.ru
2. Проверьте, что вы вошли в правильный аккаунт
3. Попробуйте найти раздел "Управление DNS" или "DNS записи"
4. Если не нашли, обратитесь в поддержку Reg.ru

### Проблема: DNS серверы не меняются

**Решение:**
1. Убедитесь, что домен не заблокирован
2. Проверьте, что прошло достаточно времени с момента регистрации домена
3. Обратитесь в поддержку Reg.ru
