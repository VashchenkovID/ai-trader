# План рефакторинга детальной страницы акций

## 🎯 Цель

Создать структурированную, информативную и удобную страницу детального просмотра акции, которая объединяет все необходимые данные для принятия торговых решений в одном месте.

## 🏗️ Детальная структура компонентов

### 1. HEADER (Верхняя панель)

**Компонент: `StockDetailHeader`**

**Содержимое:**
- Кнопка "Назад" (←)
- Основная информация:
  - Ticker (крупно, жирно)
  - Название компании
  - Сектор (badge)
  - Текущая цена (крупно, с изменением в %)
  - Валюта
- Быстрые действия:
  - Кнопка "Анализ" (AnalyzeButton)
  - Кнопка "Обучение" (TrainButton)
  - Кнопка "Купить" (BuyButton)
  - Кнопка "В избранное" (Watchlist)

**Дизайн:**
- Фиксированная высота: ~80px
- Sticky при скролле
- Градиентный фон или карточка

---

### 2. СЕКЦИЯ 1: Торговые параметры и рекомендации (Левая колонка, ~300px)

#### 2.1. Карточка "Текущая цена"
**Компонент: `CurrentPriceCard`**

**Содержимое:**
- Текущая цена (крупно)
- Изменение за день:
  - Абсолютное (₽)
  - Процентное (%)
  - Стрелка вверх/вниз
  - Цвет (зеленый/красный)
- Время последнего обновления
- WebSocket индикатор (live обновления)

**Дизайн:**
- Карточка с тенью
- Крупные цифры
- Анимация при изменении цены

---

#### 2.2. Карточка "Стоп-лосс"
**Компонент: `StopLossCard`**

**Содержимое:**
- Цена стоп-лосса
- Расстояние от текущей цены:
  - В рублях
  - В процентах
- Визуальный индикатор близости (прогресс-бар)
  - Зеленый: >10%
  - Желтый: 5-10%
  - Красный: <5%
- Предупреждение, если слишком близко

**Дизайн:**
- Карточка с акцентом на красный цвет
- Иконка ⚠️

---

#### 2.3. Карточка "Тейк-профит"
**Компонент: `TakeProfitCard`**

**Содержимое:**
- Цена тейк-профита
- Потенциальная прибыль:
  - В рублях
  - В процентах
- Визуальный индикатор прогресса (прогресс-бар)
- Risk/Reward соотношение

**Дизайн:**
- Карточка с акцентом на зеленый цвет
- Иконка ✅

---

#### 2.4. Карточка "Общая рекомендация"
**Компонент: `MainRecommendationCard`**

**Содержимое:**
- Рекомендация (BUY/SELL/HOLD) - крупно
- Confidence (уверенность):
  - Процент
  - Прогресс-бар
  - Цветовая индикация
- Score (общий балл)
- Целевая цена (targetPrice)
- Дата анализа
- Кнопка "Обновить анализ"

**Дизайн:**
- Большая карточка
- Цветовая схема по типу рекомендации:
  - BUY: зеленый
  - SELL: красный
  - HOLD: серый/желтый

---

#### 2.5. Карточка "Weekly Forecast рекомендация"
**Компонент: `WeeklyForecastRecommendationCard`**

**Содержимое:**
- Прогноз на 7 дней:
  - Ожидаемая цена через 7 дней
  - Изменение в %
  - Тренд (BULLISH/BEARISH/SIDEWAYS)
- Confidence Score
- Volatility (волатильность)
- Кнопка "Подробнее" → переход на WeeklyForecastDetail

**Дизайн:**
- Карточка с иконкой 📈
- Мини-график прогноза (опционально)

---

#### 2.6. Карточка "Классические рекомендации по стратегиям"
**Компонент: `StrategyRecommendationsCard`**

**Содержимое:**
- Три стратегии с рекомендациями:
  - **Агрессивная стратегия** (🔴):
    - Рекомендация (BUY/SELL/HOLD)
    - Confidence (в %)
    - Объяснение/обоснование
    - Целевая цена (если есть)
  - **Умеренная стратегия** (🟡):
    - Рекомендация (BUY/SELL/HOLD)
    - Confidence (в %)
    - Объяснение/обоснование
    - Целевая цена (если есть)
  - **Консервативная стратегия** (🟢):
    - Рекомендация (BUY/SELL/HOLD)
    - Confidence (в %)
    - Объяснение/обоснование
    - Целевая цена (если есть)

**Источник данных:**
- Из `recommendation.explanation.details.ensemble.horizons` (как в `RecommendationCard.tsx`)
- Или из `recommendation.horizons` (если доступно)
- Стратегии: `strategies.aggressive`, `strategies.moderate`, `strategies.conservative`

**Дизайн:**
- Карточка с иконкой 📊
- Три колонки или вертикальный список стратегий
- Badge для каждой стратегии с цветом (красный/желтый/зеленый)
- Badge для рекомендации (BUY/SELL/HOLD) с соответствующим цветом
- Прогресс-бар или процент для confidence
- Свернуть/развернуть для подробностей

**Визуализация:**
```
┌─────────────────────────────────────────┐
│ 📊 Рекомендации по стратегиям           │
├─────────────────────────────────────────┤
│ 🔴 Агрессивная    │ 🟡 Умеренная        │
│    BUY 85%        │    HOLD 60%         │
│    Краткосрочный  │    Среднесрочный    │
│    рост ожидается │    консолидация     │
├─────────────────────────────────────────┤
│ 🟢 Консервативная                      │
│    SELL 45%                            │
│    Долгосрочный                        │
│    спад возможен                       │
└─────────────────────────────────────────┘
```

### 3. СЕКЦИЯ 2: Графики и визуализация (Центр, широкая колонка)

#### 3.1. Основной график цены
**Компонент: `EnhancedPriceChart`**

**Содержимое:**
- Исторические свечи (OHLC)
- Weekly Forecast прогноз (7 дней вперед):
  - Линия прогноза
  - Область неопределенности (confidence bands)
- Ключевые уровни (линии):
  - Текущая цена (горизонтальная линия)
  - Стоп-лосс (красная пунктирная)
  - Тейк-профит (зеленая пунктирная)
  - Целевая цена (синяя пунктирная)
- Технические индикаторы (опционально):
  - SMA/EMA
  - Bollinger Bands
  - Support/Resistance уровни
- Интерактивность:
  - Zoom
  - Pan
  - Tooltip с деталями
  - Переключение периодов (1D, 1W, 1M, 3M, 1Y, All)

**Дизайн:**
- Высокий график (~500px)
- Адаптивный (Chart.js или Recharts)
- Темная/светлая тема

---

#### 3.2. График объема
**Компонент: `VolumeChart`**

**Содержимое:**
- Объемы торгов по дням
- Синхронизация с основным графиком
- Средний объем (линия)

**Дизайн:**
- Под основным графиком
- Высота ~150px

---

#### 3.3. Технические индикаторы (мини-панель)
**Компонент: `TechnicalIndicatorsPanel`**

**Содержимое:**
- RSI (мини-график + значение)
- MACD (мини-график + значения)
- Bollinger Bands (статус)
- SMA/EMA (значения)
- ATR (волатильность)

**Дизайн:**
- Компактные мини-графики
- Цветовая индикация (перекупленность/перепроданность)

---

### 4. СЕКЦИЯ 3: Дополнительная информация (Правая колонка, ~300px)

**Содержимое:**

  - Тип (BUY/SELL)

**Дизайн:**
- Компактные карточки
- Цветовая индикация по типу
- Скроллируемый список

---

#### 4.2. Последние новости
**Компонент: `RecentNewsWidget`**

**Содержимое:**
- Последние 5-7 новостей

  - Заголовок
  - Дата
  - Источник
  - Sentiment (положительный/отрицательный/нейтральный)
  - Релевантность

**Дизайн:**
- Компактные карточки
- Иконка sentiment
- Скроллируемый список

#### 4.3. Фундаментальные показатели

## 📱 Адаптивность

### Desktop (>1200px)
- 3-колоночная сетка
- Все секции видны одновременно
- Боковые панели фиксированной ширины

### Tablet (768px - 1200px)
- 2-колоночная сетка
- Графики и левая панель
- Правая панель под графиками

### Mobile (<768px)
- 1 колонка

- Сворачиваемые панели
- Мобильные оптимизированные графики

## 🔄 WebSocket обновления

### Реал-тайм данные:
1. **Цена акции** - обновление каждые N секунд
2. **Сигналы** - push при появлении нового
3. **Новости** - push при появлении новой
4. **Рекомендации** - push при обновлении анализа

### Индикаторы обновления:
- Пульсирующая точка для live данных
- Анимация при изменении значений
- Toast уведомления для важных событий

## 🎨 Дизайн-система

### Цветовая схема:
- **BUY/Положительное**: `#10b981` (green-500)
- **SELL/Отрицательное**: `#ef4444` (red-500)
- **HOLD/Нейтральное**: `#f59e0b` (amber-500)
- **Информация**: `#3b82f6` (blue-500)
- **Предупреждение**: `#f59e0b` (amber-500)
- **Опасность**: `#ef4444` (red-500)

### Типографика:
- Заголовки: Inter, 24-32px, bold
- Подзаголовки: Inter, 18-20px, semibold
- Текст: Inter, 14-16px, regular
- Цифры: JetBrains Mono, 20-48px, bold (для цен)

### Отступы:
- Карточки: 16px padding
- Секции: 24px margin между секциями
- Контент: 16px padding страницы

## 🔌 API endpoints для использования

### Существующие:
- `GET /api/market/stock/:figi` - основная информация
- `GET /api/market/stock/:figi/candles` - свечи
- `GET /api/market/stock/:figi/latest-recommendation` - рекомендация
- `GET /api/weekly-forecast/:figi` - Weekly Forecast
- `GET /api/signals/:figi` - сигналы
- `GET /api/news/:figi` - новости
- `GET /api/fundamental-data/:figi` - фундаментальные данные

### Новые (если нужны):
- `GET /api/market/stock/:figi/aggregated` - агрегированные данные (опционально)
- `GET /api/market/stock/:figi/technical-indicators` - технические индикаторы
- `GET /api/market/stock/:figi/portfolio-position` - позиция в портфеле (если есть)
