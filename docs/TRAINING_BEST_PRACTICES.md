## 🆕 Новые возможности

### Bayesian Optimization для гиперпараметров ✅

**Что это:** Более эффективный метод оптимизации гиперпараметров, который использует вероятностную модель для выбора следующих параметров для тестирования.

**Преимущества:**
- В 3-5 раз быстрее grid search для больших пространств параметров
- Автоматический выбор оптимальных параметров
- Использует Expected Improvement для максимизации эффективности

**Как работает:**
1. Начинает с 5 случайных образцов
2. Строит вероятностную модель на основе наблюдений
3. Выбирает следующие параметры, которые максимизируют Expected Improvement
4. Повторяет до 20 итераций

**Использование:**
```javascript
// Используется по умолчанию
const result = await OptimizedTrainingService.tuneHyperparameters(figis);

// Можно явно указать метод
const result = await OptimizedTrainingService.tuneHyperparameters(figis, {
    useBayesian: true // или false для grid search
});
```

### Триггерное обучение при дрейфе данных ✅

**Что это:** Автоматическое обнаружение изменения распределения данных и запуск переобучения.

**Как работает:**
1. Ежедневно в 2:00 проверяет все инструменты на дрейф данных
2. Сравнивает текущее распределение фичей с базовым (из последнего обучения)
3. Вычисляет дрейф-скор (изменение среднего и стандартного отклонения)
4. При дрейфе >30% автоматически запускает переобучение

**Преимущества:**
- Автоматическая адаптация к изменению рыночных условий
- Предотвращение деградации модели
- Уведомления в Telegram при обнаружении дрейфа

**Настройка:**
- Порог дрейфа: 30% (можно настроить)
- Частота проверки: ежедневно в 2:00
- Автоматический запуск: включен по умолчанию

### SMOTE для балансировки классов ✅

**Что это:** Генерация синтетических образцов для балансировки классов при сильном дисбалансе.

**Как работает:**
1. Определяет класс меньшинства (меньше образцов)
2. Для каждого образца меньшинства находит k ближайших соседей
3. Генерирует синтетические образцы между образцом и случайным соседом
4. Применяется автоматически при дисбалансе >70%

**Преимущества:**
- Улучшает обучение при сильном дисбалансе классов
- Работает совместно с focal loss
- Автоматическое применение без ручной настройки

**Параметры:**
- Порог применения: дисбаланс >70%
- k соседей: 5 (по умолчанию)
- Целевое соотношение: 80% (не полный баланс, чтобы избежать переобучения)
