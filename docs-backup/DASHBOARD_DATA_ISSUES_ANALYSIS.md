# Анализ проблем с отсутствующими данными на Dashboard

## 🔍 Выявленные проблемы

### 1. Sharpe Ratio показывает "— N/A"
**Причина:**
- Sharpe Ratio возвращается как `0` из API, если нет данных для расчета (нет сделок или волатильность = 0)
- В `ProfitabilityTracker.calculateMetrics()` возвращается `sharpeRatio: 0` если `volatility === 0` или нет данных
- В `client/src/pages/Dashboard.tsx` проверка `sharpeRatio != null` не учитывает случай когда значение = 0

**Решение:**
- Улучшить проверку: `sharpeValue != null && sharpeValue !== 0 && !isNaN(sharpeValue)`
- Показывать "—" если значение = 0 (нет данных для расчета)

### 2. Продвинутые метрики пустые (Sortino, Calmar, Max Drawdown)
**Причина:**
- Метрики возвращаются как `0` если нет данных для расчета
- `ProfitabilityTracker.analyzeProfitability()` может вернуть пустой массив `stats` если нет сделок за период
- `calculateAdvancedMetrics()` возвращает `0` для всех метрик если нет данных

**Решение:**
- Улучшить проверку в компоненте: проверять что значение не равно 0 и не null
- Показывать "—" если метрика = 0 (нет данных)
- Добавить подсказку что метрики требуют наличия сделок для расчета

### 3. Инфляция показывает "— —"
**Причина:**
- В `MacroDataService.fetchCbrData()` инфляция не собирается (строка 527-532)
- Комментарий в коде: "Пока пропускаем, так как инфляцию можно получить от Росстата"
- Но в `fetchRosstatData()` нет источника для инфляции, только для ВВП, безработицы и промышленного производства

**Решение:**
- Добавить сбор инфляции из Росстата через Investing.com
- Или добавить парсинг инфляции с сайта ЦБ РФ
- Или использовать альтернативный источник

### 4. RVI показывает "— —"
**Причина:**
- RVI собирается через `fetchMoexData()` из Investing.com
- Парсинг может не работать из-за изменений в структуре HTML страницы
- Или данные не сохраняются в БД из-за ошибок валидации

**Решение:**
- Проверить работу парсера `parseInvestingRviHtml()`
- Добавить логирование ошибок парсинга
- Проверить наличие данных в БД
- Возможно требуется обновление парсера под новую структуру HTML
