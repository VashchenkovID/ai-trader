# Чеклист тестирования Dashboard

## ✅ Проверка компонентов

### 1. HeroMetricsCard (Верхняя панель метрик)
- [ ] Отображается баланс портфеля с правильным форматированием
- [ ] Показывается изменение за день (↑↓) с цветовым кодированием
- [ ] Отображается PnL с прогресс-баром
- [ ] Показывается Win Rate с цветовой индикацией (зеленый >60%, желтый 40-60%, красный <40%)
- [ ] Отображается Sharpe Ratio с оценкой качества (отлично/хорошо/плохо)
- [ ] Все метрики загружаются без ошибок

### 2. AdvancedMetricsPreview (Продвинутые метрики)
- [ ] Отображается Sortino Ratio с подсказкой
- [ ] Отображается Calmar Ratio с подсказкой
- [ ] Отображается Max Drawdown
- [ ] Кнопка "Подробные метрики" ведет на `/advanced-metrics`
- [ ] Данные загружаются без ошибок

### 3. MacroDataPreview (Макро-данные)
- [ ] Отображается ставка ЦБ РФ с датой и изменением
- [ ] Отображается инфляция с датой и изменением
- [ ] Отображается ВВП с датой и изменением
- [ ] Отображается RVI с датой и изменением
- [ ] Показываются тренды (↑↓) с цветовым кодированием
- [ ] Данные загружаются без ошибок

### 4. RebalancingStatusCard (Статус ребалансировки)
- [ ] Отображается статус сервиса (включен/выключен)
- [ ] Показывается время последней проверки
- [ ] Показывается время последней ребалансировки
- [ ] Кнопка "Проверить сейчас" работает
- [ ] После проверки показывается результат (требуется/не требуется)
- [ ] Показываются уведомления через Toast

### 5. TradingSummaryCard (Торговая активность)
- [ ] Отображается количество активных позиций
- [ ] Показывается общая стоимость позиций
- [ ] Отображаются топ-3 рекомендации с:
  - Названием инструмента и тикером
  - Стратегией
  - Уверенностью (прогресс-бар)
  - Кнопкой "Купить"
- [ ] Кнопка "Запустить анализ рынка" работает
- [ ] Ссылка "Просмотреть портфель" ведет на `/portfolio`

### 6. Статус системы (рефакторинг)
- [ ] Отображаются статусы компонентов (Нейросеть, WebSocket, Торговый движок, БД)
- [ ] Показываются прогресс-бары для CPU и памяти
- [ ] Цветовая индикация ресурсов (зеленый <70%, желтый 70-90%, красный >90%)
