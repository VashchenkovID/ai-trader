# План оптимизации фронтенд части приложения

## 📋 Обзор

После добавления множества новых фич (оптимизация портфеля, макроэкономические данные, продвинутые метрики, ребалансировка портфеля) необходимо оптимизировать существующие страницы для максимальной интуитивности и понятности даже для неподготовленных пользователей.

## 🎯 Принципы оптимизации

1. **Простота и ясность** - каждый элемент должен иметь понятное назначение
2. **Визуальная иерархия** - важная информация выделяется, второстепенная скрывается
3. **Контекстная помощь** - подсказки и объяснения там, где они нужны
4. **Прогрессивное раскрытие** - детали доступны по запросу, но не перегружают интерфейс
5. **Визуализация данных** - графики и диаграммы вместо сырых чисел где возможно
6. **Цветовое кодирование** - зеленый = хорошо, красный = плохо, желтый = внимание

## 📊 Этап 1: Оптимизация Dashboard (Главная страница)

### Текущие проблемы:
- Много технической информации без контекста
- Нет интеграции новых фич (продвинутые метрики, ребалансировка, макро-данные)
- Слабая визуальная иерархия
- Нет "быстрого взгляда" на состояние системы

### Целевое состояние:
Dashboard должен давать **мгновенное понимание** состояния торговой системы и портфеля за 3 секунды.

### План изменений:

#### 1.1. Верхняя панель "Ключевые метрики" (Hero Section)
**Расположение:** Верх страницы, полная ширина, 1 строка

**Элементы:**
- **Баланс портфеля** (крупный шрифт, цвет по знаку)
  - Текущая стоимость
  - Изменение за день (+/- в рублях и %)
  - Иконка тренда (↑↓)
- **Прибыль/Убыток** (PnL)
  - Общая прибыль/убыток
  - Процент от начального капитала
  - Визуальный индикатор (полоса прогресса)
- **Win Rate**
  - Процент успешных сделок
  - Количество сделок
  - Цветовая индикация (зеленый >60%, желтый 40-60%, красный <40%)
- **Sharpe Ratio** (продвинутая метрика)
  - Текущее значение
  - Индикатор качества (отлично >1.5, хорошо >1.0, плохо <1.0)
- **Статус ребалансировки** (новая фича)
  - Индикатор необходимости ребалансировки
  - Время до следующей проверки
  - Кнопка "Проверить сейчас"

**Визуализация:**
- Карточки с крупными числами
- Цветовое кодирование (зеленый/красный/желтый)
- Иконки для быстрого понимания

#### 1.2. Блок "Состояние системы" (упрощенный)
**Расположение:** Слева, 2 колонки

**Элементы:**
- **Статус компонентов** (упрощенный вид)
  - Нейросеть: ✅ Готова / ⚠️ Обучение / ❌ Ошибка
  - Торговый движок: ✅ Активен / ⚠️ Пауза / ❌ Остановлен
  - WebSocket: ✅ Подключен / ❌ Отключен
  - База данных: ✅ Работает / ❌ Ошибка
- **Ресурсы сервера** (компактный вид)
  - CPU: прогресс-бар с процентом
  - Память: прогресс-бар с процентом
  - Цветовая индикация (зеленый <70%, желтый 70-90%, красный >90%)

**Визуализация:**
- Компактные карточки с иконками
- Прогресс-бары вместо чисел
- Минимум текста

#### 1.3. Блок "Торговая активность" (расширенный)
**Расположение:** Центр, 2 колонки

**Элементы:**
- **Активные позиции**
  - Количество открытых позиций
  - Общая стоимость позиций
  - Средняя прибыль/убыток по позициям
  - Ссылка "Просмотреть портфель"
- **Топ-3 рекомендации** (улучшенный вид)
  - Карточки с крупными данными
  - Кнопка "Купить" прямо на карточке
  - Индикатор уверенности (полоса прогресса)
  - Ссылка на детальную страницу инструмента

**Визуализация:**
- Карточки с изображениями/иконками инструментов
- Крупные кнопки действий
- Визуальные индикаторы уверенности

#### 1.4. Блок "Продвинутые метрики" (новая секция)
**Расположение:** Справа, 1 колонка

**Элементы:**
- **Sortino Ratio** (риск-скорректированная доходность)
  - Значение с объяснением
  - Индикатор качества
- **Calmar Ratio** (доходность/макс. просадка)
  - Значение с объяснением
  - Индикатор качества
- **Максимальная просадка**
  - Текущее значение
  - Визуализация на графике
- **Ссылка:** "Подробные метрики" → `/advanced-metrics`

**Визуализация:**
- Компактные карточки с мини-графиками
- Подсказки при наведении (tooltips)
- Цветовое кодирование

#### 1.5. Блок "Макроэкономические данные" (новая секция)
**Расположение:** Нижняя часть, 1 строка

**Элементы:**
- **Ключевые индикаторы** (компактный вид)
  - Ставка ЦБ РФ: значение + изменение
  - Инфляция: значение + изменение
  - ВВП: значение + изменение
  - RVI (индекс волатильности): значение + изменение
- **Визуализация:** Мини-графики трендов (↑↓)
- **Ссылка:** "Подробнее" → новая страница макро-данных

**Визуализация:**
- Компактная таблица с иконками
- Цветовое кодирование изменений (зеленый рост, красный падение)
- Мини-графики трендов

#### 1.6. Блок "Быстрые действия"
**Расположение:** Нижняя часть, кнопки действий

**Элементы:**
- Кнопка "Запустить анализ рынка" (крупная, заметная)
- Кнопка "Проверить ребалансировку" (новая)
- Кнопка "Оптимизировать портфель" (новая)
- Кнопка "Обновить данные" (вторичная)

**Визуализация:**
- Крупные кнопки с иконками
- Цветовое выделение важных действий

### Файлы для изменения:
- `client/src/pages/Dashboard.tsx` - основная страница
- `client/src/components/dashboard/TradingSummaryCard.tsx` - карточка торговой сводки
- `client/src/components/dashboard/QuickLinksAndSystemCard.tsx` - быстрые ссылки
- Новые компоненты:
  - `client/src/components/dashboard/HeroMetricsCard.tsx` - верхняя панель метрик
  - `client/src/components/dashboard/AdvancedMetricsPreview.tsx` - превью продвинутых метрик
  - `client/src/components/dashboard/MacroDataPreview.tsx` - превью макро-данных
  - `client/src/components/dashboard/RebalancingStatusCard.tsx` - статус ребалансировки

## 💼 Этап 2: Оптимизация Portfolio (Портфель)

### Текущие проблемы:
- Слабая визуализация распределения капитала
- Нет информации о ребалансировке
- Нет информации об оптимизации портфеля
- Сложно понять, какие позиции требуют внимания

### Целевое состояние:
Портфель должен показывать **полную картину** инвестиций с акцентом на **действия**, которые нужно предпринять.

### План изменений:

#### 2.1. Верхняя панель "Сводка портфеля" (Hero Section)
**Расположение:** Верх страницы, полная ширина

**Элементы:**
- **Общая стоимость портфеля** (крупный шрифт)
  - Текущая стоимость
  - Изменение за день
  - Изменение за период (7 дней, 30 дней, год)
- **Распределение капитала**
  - Круговая диаграмма: наличные / инвестированные
  - Процентное соотношение
- **Ключевые метрики**
  - Общая прибыль/убыток
  - Процент доходности
  - Количество позиций
  - Средняя прибыль на позицию

**Визуализация:**
- Крупные числа с цветовым кодированием
- Круговая диаграмма для распределения
- Мини-график изменения стоимости

#### 2.2. Блок "Алерты и рекомендации"
**Расположение:** Сразу после сводки, выделенный блок

**Элементы:**
- **Требуется ребалансировка** (новая фича)
  - Индикатор отклонения от целевых весов
  - Список позиций, требующих корректировки
  - Кнопка "Выполнить ребалансировку"
  - Предпросмотр операций (dry-run)
- **Рекомендации на продажу**
  - Позиции с отрицательными сигналами
  - Причина рекомендации
  - Кнопка "Продать"
- **Рекомендации на покупку**
  - Инструменты для допокупки
  - Обоснование рекомендации
  - Кнопка "Купить"

**Визуализация:**
- Цветные карточки (желтый для ребалансировки, красный для продажи, зеленый для покупки)
- Иконки для быстрого понимания
- Крупные кнопки действий

#### 2.3. Блок "Распределение по стратегиям"
**Расположение:** Левая колонка

**Элементы:**
- **Карточки стратегий** (консервативная, умеренная, агрессивная)
  - Текущий вес в портфеле
  - Целевой вес
  - Отклонение от цели
  - Прибыль/убыток по стратегии
  - Количество позиций
- **Визуализация:** Столбчатая диаграмма (текущий vs целевой вес)

**Визуализация:**
- Карточки с цветовым кодированием
- Столбчатая диаграмма
- Индикаторы отклонения

#### 2.4. Блок "Распределение по секторам"
**Расположение:** Правая колонка

**Элементы:**
- **Круговая диаграмма** распределения по секторам
- **Таблица секторов** с деталями:
  - Название сектора
  - Вес в портфеле
  - Количество позиций
  - Средняя прибыль/убыток
- **Рекомендации** по диверсификации (если есть перекосы)

**Визуализация:**
- Круговая диаграмма
- Таблица с сортировкой
- Цветовое кодирование

#### 2.5. Блок "Оптимизация портфеля" (новая секция)
**Расположение:** Центральная часть

**Элементы:**
- **Текущая конфигурация**
  - Метод оптимизации (Mean-Variance, Black-Litterman, Risk Parity)
  - Sharpe Ratio текущего портфеля
  - Ожидаемая доходность
  - Ожидаемый риск (волатильность)
- **Рекомендуемая конфигурация**
  - Предложение по оптимизации
  - Улучшение Sharpe Ratio
  - Изменения в распределении
  - Кнопка "Применить оптимизацию"
- **Эффективная граница** (Efficient Frontier)
  - График риск/доходность
  - Текущая точка
  - Оптимальная точка

**Визуализация:**
- График эффективной границы
- Сравнительная таблица (текущий vs оптимальный)
- Кнопки действий

#### 2.6. Блок "История ребалансировок" (новая секция)
**Расположение:** Нижняя часть

**Элементы:**
- **Таблица последних ребалансировок**
  - Дата и время
  - Триггер (автоматический/ручной)
  - Количество операций
  - Комиссия
  - Результат (улучшение/ухудшение метрик)
- **Фильтры:** по дате, по триггеру
- **Ссылка:** "Подробная история"

**Визуализация:**
- Компактная таблица
- Цветовое кодирование результатов
- Иконки для типов операций

#### 2.7. Таблица позиций (улучшенная)
**Расположение:** Основная часть страницы

**Улучшения:**
- **Группировка** по стратегиям или секторам
- **Сортировка** по прибыли/убытку, весу, дате открытия
- **Фильтры:** по стратегии, сектору, статусу (прибыльные/убыточные)
- **Колонки:**
  - Инструмент (с иконкой и ссылкой)
  - Стратегия (цветной бейдж)
  - Количество
  - Средняя цена входа
  - Текущая цена
  - Прибыль/убыток (абсолютный и процентный, цветовое кодирование)
  - Вес в портфеле (с индикатором отклонения от цели)
  - Рекомендация AI (BUY/SELL/HOLD с уверенностью)
  - Действия (кнопки: Продать, Дополнить, Детали)

**Визуализация:**
- Цветовое кодирование строк (зеленый = прибыль, красный = убыток)
- Индикаторы отклонения от целевого веса
- Крупные кнопки действий
- Подсказки при наведении

### Файлы для изменения:
- `client/src/pages/Portfolio.tsx` - основная страница
- `client/src/components/PortfolioVisualization.tsx` - основной компонент
- `client/src/components/portfolio/PortfolioSummaryCard.tsx` - карточка сводки
- `client/src/components/portfolio/PortfolioPositionsTable.tsx` - таблица позиций
- Новые компоненты:
  - `client/src/components/portfolio/RebalancingAlertCard.tsx` - алерт ребалансировки
  - `client/src/components/portfolio/PortfolioOptimizationCard.tsx` - оптимизация портфеля
  - `client/src/components/portfolio/RebalancingHistoryTable.tsx` - история ребалансировок
  - `client/src/components/portfolio/StrategyAllocationChart.tsx` - график распределения по стратегиям
  - `client/src/components/portfolio/SectorAllocationChart.tsx` - график распределения по секторам

## ⭐ Этап 3: Оптимизация Recommendations (Рекомендации)

### Текущие проблемы:
- Много технических деталей без контекста
- Нет информации о влиянии макро-данных на рекомендации
- Слабая визуализация уверенности и рисков
- Нет связи с текущим портфелем

### Целевое состояние:
Рекомендации должны быть **понятными и действенными** с четким обоснованием.

### План изменений:

#### 3.1. Верхняя панель "Фильтры и поиск" (улучшенная)
**Расположение:** Верх страницы

**Улучшения:**
- **Умные фильтры:**
  - По типу рекомендации (BUY/SELL/HOLD)
  - По стратегии
  - По уверенности (минимальный порог)
  - По сектору
  - По горизонту (краткосрочные/среднесрочные/долгосрочные)
- **Поиск:** по названию, тикеру, FIGI
- **Сортировка:** по уверенности, score, дате анализа
- **Визуализация:** Количество рекомендаций по каждому фильтру

#### 3.2. Блок "Контекст макро-данных" (новая секция)
**Расположение:** Над таблицей рекомендаций

**Элементы:**
- **Текущее состояние рынка**
  - Ставка ЦБ РФ и её влияние на рекомендации
  - Инфляция и её влияние
  - RVI (индекс волатильности) и его влияние
  - Общий тренд рынка (бычий/медвежий/нейтральный)
- **Визуализация:** Компактные карточки с иконками и цветовым кодированием

#### 3.3. Карточки рекомендаций (улучшенный вид)
**Расположение:** Основная часть (альтернатива таблице)

**Элементы для каждой рекомендации:**
- **Заголовок карточки:**
  - Название инструмента (крупный шрифт)
  - Тикер и сектор
  - Иконка типа рекомендации (BUY/SELL/HOLD)
- **Ключевые метрики:**
  - Уверенность (крупный процент с цветовым кодированием)
  - Score (число с объяснением)
  - Цена анализа vs текущая цена (изменение)
- **Рекомендации по горизонтам:**
  - Краткосрочный (1-7 дней): BUY/SELL/HOLD с уверенностью
  - Среднесрочный (1-4 недели): BUY/SELL/HOLD с уверенностью
  - Долгосрочный (1-3 месяца): BUY/SELL/HOLD с уверенностью
  - Визуализация: Цветные бейджи с процентами
- **Цены и риски:**
  - Текущая цена
  - Целевая цена (take profit)
  - Стоп-лосс
  - Риск/награда (risk/reward ratio)
  - Визуализация: Мини-график с уровнями цен
- **Обоснование:**
  - Краткое объяснение (1-2 предложения)
  - Кнопка "Подробнее" для полного анализа
- **Действия:**
  - Кнопка "Купить" (для BUY) или "Продать" (для SELL)
  - Кнопка "Добавить в избранное"
  - Кнопка "Поделиться"

**Визуализация:**
- Карточки с цветовым кодированием (зеленый = BUY, красный = SELL, серый = HOLD)
- Крупные кнопки действий
- Мини-графики цен
- Иконки для быстрого понимания

#### 3.4. Таблица рекомендаций (улучшенная)
**Расположение:** Альтернативный вид (переключатель: карточки/таблица)

**Улучшения колонок:**
- **Инструмент:** Название + тикер + иконка сектора
- **Рекомендация:** Крупный бейдж с иконкой (BUY/SELL/HOLD)
- **Уверенность:** Прогресс-бар + процент (цветовое кодирование)
- **Score:** Число + индикатор качества (отлично/хорошо/плохо)
- **Горизонты:** Компактные бейджи (S/M/L) с цветовым кодированием
- **Цены:** Текущая / Целевая / Стоп-лосс (с изменениями)
- **Риск/Награда:** Число + индикатор (высокий/средний/низкий)
- **Макро-контекст:** Иконки влияющих факторов (ставка ЦБ, инфляция, RVI)
- **Дата анализа:** Дата + время с индикатором свежести
- **Действия:** Кнопки (Купить/Продать/Детали)

**Визуализация:**
- Цветовое кодирование строк по типу рекомендации
- Прогресс-бары для уверенности
- Иконки для макро-контекста
- Крупные кнопки действий

#### 3.5. Блок "Связь с портфелем" (новая секция)
**Расположение:** Боковая панель или нижняя часть

**Элементы:**
- **Рекомендации для текущего портфеля**
  - Инструменты, которые уже есть в портфеле
  - Рекомендации на допокупку/продажу
  - Приоритетные действия
- **Диверсификация**
  - Рекомендации для улучшения диверсификации
  - Недостающие секторы
  - Перекосы в портфеле

**Визуализация:**
- Выделенные карточки для портфельных рекомендаций
- Индикаторы приоритета

## 📋 Этап 4: Оптимизация TradingRequests (Торговые заявки)

### Текущие проблемы:
- Много технических деталей без объяснений
- Слабая визуализация статусов и приоритетов
- Нет связи с рекомендациями и портфелем
- Сложно понять, какие заявки требуют внимания

### Целевое состояние:
Торговые заявки должны быть **понятными и управляемыми** с четкими действиями.

### План изменений:

#### 4.1. Верхняя панель "Статистика заявок" (улучшенная)
**Расположение:** Верх страницы

**Элементы:**
- **Общая статистика:**
  - Всего заявок
  - Ожидающие одобрения (выделено)
  - Одобренные
  - Исполненные
  - Отклоненные
- **Фильтры по режимам:**
  - Paper Trading
  - Micro Trading
  - Real Trading
  - Все режимы
- **Быстрые действия:**
  - Кнопка "Одобрить все безопасные" (для заявок с высокой уверенностью)
  - Кнопка "Отклонить все рискованные" (для заявок с низкой уверенностью)

**Визуализация:**
- Карточки со статистикой (цветовое кодирование)
- Крупные числа
- Кнопки быстрых действий

#### 4.2. Блок "Требуют внимания" (новая секция)
**Расположение:** Сразу после статистики

**Элементы:**
- **Срочные заявки** (приоритет URGENT)
  - Список заявок с истекающим сроком
  - Таймер до истечения
  - Кнопки быстрого одобрения/отклонения
- **Высокорискованные заявки**
  - Заявки с высоким риском
  - Причина риска
  - Рекомендация (одобрить/отклонить)
- **Заявки с низкой уверенностью**
  - Заявки с confidence < 0.6
  - Предупреждение о риске
  - Рекомендация пересмотреть

**Визуализация:**
- Выделенные карточки (желтый/красный фон)
- Таймеры обратного отсчета
- Крупные кнопки действий

#### 4.3. Таблица заявок (улучшенная)
**Расположение:** Основная часть страницы

**Улучшения:**
- **Группировка:** по статусу, по приоритету, по дате
- **Сортировка:** по приоритету, по дате создания, по уверенности
- **Фильтры:** по статусу, приоритету, риску, режиму торговли
- **Колонки:**
  - Чекбокс для выбора (для массовых действий)
  - Инструмент (название + тикер + иконка)
  - Действие (BUY/SELL с цветовым кодированием)
  - Количество и цена (с расчетом суммы)
  - Уверенность (прогресс-бар + процент)
  - Score (число + индикатор)
  - Статистика инструмента (Win Rate, Kelly Fraction) - новая колонка
  - Статус (крупный бейдж с цветом)
  - Приоритет (бейдж с цветом)
  - Риск (бейдж с цветом)
  - Режим торговли (бейдж)
  - Дата создания (с индикатором свежести)
  - Срок действия (с таймером)
  - Действия (кнопки: Одобрить/Отклонить/Детали/Отменить)

**Визуализация:**
- Цветовое кодирование строк по статусу
- Прогресс-бары для уверенности
- Бейджи для статусов, приоритетов, рисков
- Крупные кнопки действий
- Подсказки при наведении

#### 4.4. Карточка деталей заявки (улучшенная)
**Расположение:** Модальное окно или боковая панель

**Элементы:**
- **Основная информация:**
  - Инструмент (с ссылкой на детальную страницу)
  - Действие (BUY/SELL)
  - Количество и цена
  - Обоснование (развернутое)
- **Риск-анализ:**
  - Уровень риска

  - Рекомендации по управлению риском
- **Статистика инструмента:**
  - Win Rate
  - Kelly Fraction
  - Количество сделок
  - Средняя прибыль/убыток
- **Связь с портфелем:**
  - Есть ли уже позиция по этому инструменту
  - Влияние на диверсификацию
  - Влияние на корреляции
- **Макро-контекст:**
  - Влияющие макро-факторы

- **Действия:**
  - Кнопка "Одобрить"
  - Кнопка "Отклонить" (с полем для причины)
  - Кнопка "Изменить параметры"
  - Кнопка "Отменить"

**Визуализация:**
- Структурированные секции
- Цветовое кодирование рисков
- Графики статистики
- Крупные кнопки действий

#### 4.5. Блок "Массовые действия" (новая секция)
**Расположение:** Панель инструментов над таблицей

**Элементы:**

- **Действия:**
  - Одобрить выбранные
