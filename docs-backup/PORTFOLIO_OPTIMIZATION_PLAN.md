# План реализации оптимизации портфеля (Mean-Variance Optimization)

## 📋 Обзор

Реализация современных методов оптимизации портфеля для улучшения Sharpe Ratio на 0.2-0.4 через математически обоснованное распределение капитала между инструментами.

## 🎯 Цели

1. **Mean-Variance Optimization (Markowitz)** - Оптимальное распределение капитала с учетом ожидаемой доходности и риска
2. **Black-Litterman Model** - Учет мнений аналитиков и прогнозов AI для более точных ожидаемых доходностей
3. **Risk Parity** - Равномерное распределение риска между позициями
4. **Интеграция с существующей системой** - Использование текущих данных о корреляциях, волатильности и доходности

## 🏗️ Архитектура решения

### 1. PortfolioOptimizer (`server/src/services/PortfolioOptimizer.js`)

Основной сервис для оптимизации портфеля.

#### Основные методы:

**1.1. `meanVarianceOptimization(options)`**
- Реализация классической оптимизации Markowitz
- Параметры:
  ```javascript
  {
    instruments: Array<{figi, ticker, expectedReturn, volatility}>,
    correlationMatrix: Object, // Матрица корреляций
    totalCapital: number,
    riskFreeRate: number, // Безрисковая ставка (по умолчанию: 0.08 = 8%)
    targetReturn: number | null, // Целевая доходность (опционально)
    maxPositionSize: number, // Максимальный размер позиции (0.1 = 10%)
    minPositionSize: number, // Минимальный размер позиции (0.01 = 1%)
    constraints: {
      maxSectorExposure: number, // Максимальная экспозиция на сектор
      maxPositions: number, // Максимальное количество позиций
      longOnly: boolean // Только длинные позиции (true)
    }
  }
  ```
- Возвращает:
  ```javascript
  {
    weights: Object, // {figi: weight} - веса позиций (сумма = 1)
    expectedReturn: number, // Ожидаемая доходность портфеля
    portfolioVolatility: number, // Волатильность портфеля
    sharpeRatio: number, // Sharpe Ratio портфеля
    efficientFrontier: Array<{return, risk, sharpe}>, // Точки эффективной границы
    optimizationMethod: 'mean_variance',
    constraints: {...},
    warnings: Array<string>
  }
  ```

**1.2. `blackLittermanOptimization(options)`**
- Black-Litterman модель с учетом мнений аналитиков и AI прогнозов
- Параметры:
  ```javascript
  {
    instruments: Array<{figi, ticker}>,
    marketCapWeights: Object, // Рыночные веса (если доступны)
    views: Array<{
      instruments: Array<string>, // FIGI инструментов
      view: number, // Ожидаемая доходность в %
      confidence: number // Уверенность в мнении (0-1)
    }>,
    tau: number, // Масштабирующий параметр (по умолчанию: 0.05)
    riskAversion: number, // Коэффициент неприятия риска (по умолчанию: 3.0)
    correlationMatrix: Object,
    totalCapital: number,
    constraints: {...}
  }
  ```
- Views формируются из:
  - Прогнозов AI (`Recommendation.prediction`, `confidence`, `score`)
  - Исторической доходности инструментов
  - Аналитических мнений (если доступны)
- Возвращает: аналогично `meanVarianceOptimization`

**1.3. `riskParityOptimization(options)`**
- Risk Parity - равномерное распределение риска
- Параметры:
  ```javascript
  {
    instruments: Array<{figi, ticker, volatility}>,
    correlationMatrix: Object,
    totalCapital: number,
    targetRisk: number | null, // Целевой риск портфеля (опционально)
    constraints: {...}
  }
  ```
- Алгоритм:
  1. Расчет вклада каждого инструмента в риск портфеля
  2. Итеративная оптимизация для выравнивания вкладов в риск
  3. Учет корреляций между инструментами
- Возвращает:
  ```javascript
  {
    weights: Object,
    riskContributions: Object, // Вклад каждого инструмента в риск
    portfolioVolatility: number,
    optimizationMethod: 'risk_parity',
    iterations: number // Количество итераций до сходимости
  }
  ```

**1.4. `calculateCovarianceMatrix(instruments, correlationMatrix)`**
- Расчет матрицы ковариаций из корреляций и волатильностей
- Формула: `Cov(i,j) = Corr(i,j) * Vol(i) * Vol(j)`
- Возвращает матрицу ковариаций

**1.5. `calculateExpectedReturns(instruments, method)`**
- Расчет ожидаемых доходностей
- Методы:
  - `historical` - на основе исторических данных
  - `ai_forecast` - на основе прогнозов AI (prediction, confidence)
  - `blended` - комбинация исторических данных и AI прогнозов
- Возвращает: `{figi: expectedReturn}`

**1.6. `solveQuadraticProgram(objective, constraints)`**
- Решение задачи квадратичного программирования
- Использует библиотеку или собственный алгоритм
- Алгоритм: Sequential Quadratic Programming (SQP) или Interior Point Method
- Альтернатива: использование библиотеки `quadprog` (если доступна для Node.js)

**1.7. `generateEfficientFrontier(instruments, correlationMatrix, steps)`**
- Генерация эффективной границы (Efficient Frontier)
- Возвращает массив точек {return, risk, sharpe, weights}

**1.8. `applyConstraints(weights, constraints)`**
- Применение ограничений к весам портфеля
- Ограничения:
  - Максимальный размер позиции
  - Минимальный размер позиции
  - Максимальная экспозиция на сектор
  - Максимальное количество позиций
  - Long-only (только длинные позиции)

## 📐 Математические детали

### Mean-Variance Optimization

**Целевая функция:**
```
Maximize: μ^T * w - (λ/2) * w^T * Σ * w
Subject to:
  Σw = 1 (сумма весов = 1)
  w_i >= 0 (long-only)
  w_i <= maxPositionSize (максимальный размер позиции)
  Σ(w_i for i in sector) <= maxSectorExposure (лимит на сектор)
```

Где:
- `μ` - вектор ожидаемых доходностей
- `w` - вектор весов портфеля
- `Σ` - матрица ковариаций
- `λ` - коэффициент неприятия риска

**Альтернативная формулировка (для целевой доходности):**
```
Minimize: w^T * Σ * w (минимизация риска)
Subject to:
  μ^T * w >= targetReturn
  Σw = 1
  w_i >= 0
  (другие ограничения)
```

### Black-Litterman Model

**Шаги:**

1. **Рыночные веса (если доступны):**
   ```
   w_market = marketCapWeights
   ```

2. **Подразумеваемые доходности:**
   ```
   Π = λ * Σ * w_market
   ```
   Где `λ` - коэффициент неприятия риска

3. **Объединение мнений:**
   ```
   μ_BL = [(τΣ)^(-1) + P^T * Ω^(-1) * P]^(-1) * [(τΣ)^(-1) * Π + P^T * Ω^(-1) * Q]
   ```
   Где:
   - `P` - матрица мнений (какие инструменты в каждом мнении)
   - `Q` - вектор ожидаемых доходностей из мнений
   - `Ω` - матрица уверенности в мнениях
   - `τ` - масштабирующий параметр

4. **Ковариация:**
   ```
   Σ_BL = Σ + [(τΣ)^(-1) + P^T * Ω^(-1) * P]^(-1)
   ```

5. **Оптимизация Markowitz** с `μ_BL` и `Σ_BL`

### Risk Parity

**Целевая функция:**
```
Minimize: Σ(MC_i - MC_target)^2
Subject to:
  Σw = 1
  w_i >= 0
```

Где:
- `MC_i` - вклад инструмента i в риск портфеля
- `MC_target` - целевой вклад (равный для всех)

**Вклад в риск:**
```
MC_i = w_i * (Σ * w)_i / (w^T * Σ * w)^(1/2)
```

**Алгоритм:**
1. Инициализация равных весов
2. Расчет текущих вкладов в риск
3. Итеративная корректировка весов для выравнивания вкладов
4. Проверка сходимости

## ⚠️ Риски и ограничения

### Риски:
1. **Вычислительная сложность** - оптимизация может быть медленной для большого количества инструментов
   - **Решение:** Ограничение количества инструментов, кеширование матриц
   
2. **Нестабильность матриц** - матрица ковариаций может быть вырожденной или плохо обусловленной
   - **Решение:** Регуляризация (shrinkage), проверка обусловленности
   
3. **Неточность прогнозов** - прогнозы AI могут быть неточными
   - **Решение:** Использование blended подхода, проверка качества прогнозов
   
4. **Недостаток данных** - недостаточно исторических данных для некоторых инструментов
   - **Решение:** Использование только инструментов с достаточным количеством данных

### Ограничения:
1. **Long-only** - только длинные позиции (без шортов)
2. **Дискретизация** - веса должны быть переведены в целое количество акций
3. **Транзакционные издержки** - не учитываются при оптимизации (можно добавить позже)
4. **Ликвидность** - не учитывается напрямую (учитывается через ограничения)
