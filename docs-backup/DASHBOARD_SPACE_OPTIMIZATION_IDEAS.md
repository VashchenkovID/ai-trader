# Идеи по оптимизации пространства на Dashboard

## 🎯 Приоритетные идеи

### 1. **Сворачиваемые секции (Accordion/Panel)**
**Проблема:** Много информации занимает место
**Решение:** Использовать `Panel` из PrimeReact для сворачивания секций
- Состояние системы - можно свернуть ресурсы сервера
- Торговая активность - можно свернуть детали рекомендаций
- Управление нейросетями - можно свернуть детали обучения

**Преимущества:**
- Экономия вертикального пространства
- Пользователь сам решает, что видеть
- Сохранение состояния в localStorage

### 2. **Компактный HeroMetricsCard**
**Проблема:** 4 метрики занимают много места
**Решение:** 
- Уменьшить padding (p-3 → p-2)
- Уменьшить размер шрифтов (text-3xl → text-2xl)
- Убрать лишние описания, оставить только числа
- Использовать tooltips для дополнительной информации

### 3. **Горизонтальное расположение ресурсов сервера**
**Проблема:** CPU и память занимают вертикальное пространство
**Решение:**
- Разместить CPU и память в одну строку
- Использовать более компактные прогресс-бары
- Уменьшить отступы между элементами

### 4. **Табы для группировки информации**
**Проблема:** Много карточек на одном уровне
**Решение:** Использовать `TabView` для группировки:
- Таб "Метрики" - HeroMetricsCard + AdvancedMetricsPreview
- Таб "Система" - Состояние системы + Управление нейросетями + Кеш
- Таб "Торговля" - Торговая активность + Статус ребалансировки
- Таб "Макро" - Макроэкономические данные

### 5. **Компактные карточки рекомендаций**
**Проблема:** Карточки рекомендаций занимают много места
**Решение:**
- Использовать табличный вид вместо карточек
- Показывать только тикер и уверенность
- Полная информация в tooltip или модальном окне
- Ограничить высоту и добавить скролл

### 6. **Условное отображение**
**Проблема:** Все виджеты показываются всегда
**Решение:**
- Показывать только активные/важные виджеты
- Скрывать пустые секции
- Использовать кнопку "Показать все" для расширенного вида

### 7. **Компактные заголовки карточек**
**Проблема:** Заголовки занимают место
**Решение:**
- Убрать эмодзи из заголовков (или сделать их меньше)
- Использовать только иконки PrimeIcons
- Уменьшить размер шрифта заголовков

### 8. **Группировка статусов системы**
**Проблема:** 4 статуса в сетке 2x2 занимают место
**Решение:**
- Разместить в одну строку с разделителями
- Использовать только иконки и бейджи
- Детали в tooltip

### 9. **Адаптивные размеры**
**Проблема:** Фиксированные размеры колонок
**Решение:**
- Использовать flex вместо grid где возможно
- Автоматическое распределение пространства
- Минимальные и максимальные ширины

### 10. **Вертикальное объединение связанных карточек**
**Проблема:** Связанные карточки разбросаны
**Решение:**
- Объединить "Продвинутые метрики" и "Макро-данные" в одну карточку с табами
- Объединить "Статус ребалансировки" и "Торговая активность" (если логически связано)

## 📊 Конкретные предложения по реализации

### Вариант A: Минимальные изменения (быстро)
1. Уменьшить padding везде (p-3 → p-2, gap-3 → gap-2)
2. Уменьшить размеры шрифтов на 10-20%
3. Сделать ресурсы сервера горизонтальными
4. Компактные карточки рекомендаций

### Вариант B: Средние изменения (баланс)
1. Все из варианта A
2. Добавить сворачиваемые панели для деталей
3. Группировка статусов системы в одну строку
4. Компактный HeroMetricsCard

### Вариант C: Максимальные изменения (полная оптимизация)
1. Все из варианта B
2. Табы для группировки информации
3. Условное отображение виджетов
4. Адаптивная компоновка с flex

## 🎨 Дополнительные идеи

### 11. **Плавающие кнопки действий**
- Вынести часто используемые действия в плавающую панель
- Экономия места в карточках

### 12. **Мини-графики вместо чисел**
- Использовать sparklines для трендов
- Визуализация вместо текста

### 13. **Компактные бейджи вместо карточек**
- Для статусов использовать только бейджи
- Информация в tooltip

### 14. **Сетка с переменным количеством колонок**
- На больших экранах: 4 колонки
- На средних: 3 колонки
- На маленьких: 2 колонки

### 15. **Виртуализация списков**
- Для длинных списков использовать виртуализацию
- Показывать только видимые элементы

## 🔧 Технические детали

### Компоненты PrimeReact для использования:
- `Panel` - для сворачиваемых секций
- `TabView` / `TabPanel` - для группировки
- `Tooltip` - для дополнительной информации
- `OverlayPanel` - для выпадающих деталей
- `ScrollPanel` - для прокручиваемых списков

### CSS оптимизации:
- Использовать `gap` вместо `margin`
- Минимизировать `padding`
- Использовать `text-xs` и `text-sm` вместо стандартных размеров
- Компактные прогресс-бары (height: 4-6px)
