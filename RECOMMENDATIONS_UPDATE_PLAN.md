# 📋 План обновления страницы Recommendations

## 🎯 Цель
Обновить страницу Recommendations под новые фичи сервера и новый дизайн, упростив интерфейс для обычного пользователя.

---

## 📊 Анализ текущего состояния

### ✅ Что есть сейчас:
- Страница Recommendations.tsx с таблицей рекомендаций
- Компоненты: RecommendationTemplate, ConfidenceTemplate, HorizonsTemplate, BuyButton
- Фильтры: по типу (BUY/SELL/HOLD), по стратегии, поиск
- API: `/api/recommendations`, `/api/recommendations/type/:type`, `/api/recommendations/top`

### ⚠️ Проблемы:
- Использует PrimeReact (DataTable, Card, Button, Dropdown)
- Технические детали видны пользователю (horizons, strategy, analysis)
- Таблица не очень удобна для мобильных устройств
- Нет real-time обновлений через WebSocket
- Нет фильтра по уверенности (высокая/средняя/низкая)

### Фаза 1: Рефакторинг компонентов (2-3 часа)

#### 1.1 Создать новые компоненты рекомендаций

**RecommendationCard.tsx** - карточка рекомендации
- Использовать Card из UI-kit
- Показывать: название, тикер, цена, рекомендация, уверенность, score
- Скрыть технические детали (horizons, analysis, explanation)
- Кнопка "Купить"/"Продать" с градиентом
- Кнопка "Подробнее" для модального окна

**RecommendationFilters.tsx** - фильтры
- Использовать Select из UI-kit
- Фильтры:

  - Уверенность: Все / Высокая (>80%) / Средняя (50-80%) / Низкая (<50%)
  - Стратегия: Все / Консервативная / Умеренная / Агрессивная
- Поиск по названию/тикеру (Input из UI-kit)

**RecommendationModal.tsx** - модальное окно с деталями
- Использовать Modal из UI-kit
- Показывать технические детали (horizons, analysis)
- График цены (если доступен)
- История рекомендаций

#### 1.2 Обновить существующие компоненты

**ConfidenceTemplate.tsx** → **ConfidenceBadge.tsx**

## 🎨 Дизайн-система

### Использовать компоненты из UI-kit:
- `Card` - для карточек рекомендаций
- `Button` - для кнопок действий (с градиентом для primary)
- `Badge` - для уверенности и статусов
- `Input` - для поиска
- `Select` - для фильтров
- `Modal` - для деталей
- `Skeleton` - для loading состояний

### Цветовая схема:
- BUY: зеленый градиент (#10B981 → #059669)
- SELL: красный градиент (#EF4444 → #DC2626)
- HOLD: серый (#6B7280)
- Высокая уверенность: зеленый (#10B981)
- Средняя уверенность: желтый (#F59E0B)
- Низкая уверенность: красный (#EF4444)
