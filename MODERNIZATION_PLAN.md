### Приоритет 1: Аналитика и визуализация (P1) 🔴

#### 1.1. Дашборд производительности
**Описание:** Создать центральный дашборд с визуализацией производительности торговой системы.

**Задачи:**
- [ ] **1.1.1.** Компонент `PerformanceDashboard.tsx`:
  - График доходности по времени (линейный график)
  - Распределение прибылей/убытков (гистограмма)
  - График drawdown (областной график)
  - Ключевые метрики: общая прибыль, Win Rate, Sharpe Ratio, максимальная просадка
  - Фильтры по периодам (день, неделя, месяц, квартал, год)
  
- [ ] **1.1.2.** Heatmap производительности:
  - Компонент `PerformanceHeatmap.tsx`
  - Ось X: секторы (технологии, финансы, энергетика и т.д.)
  - Ось Y: стратегии (агрессивная, умеренная, консервативная)
  - Цветовая индикация: зеленый (прибыль), красный (убыток)
  - Интерактивность: клик по ячейке показывает детали

- [ ] **1.1.3.** Секторный анализ:
  - Компонент `SectorAnalysis.tsx`
  - Таблица с метриками по секторам:
    - Название сектора
    - Количество инструментов
    - Общая прибыль
    - Win Rate
    - Sharpe Ratio
    - Доля в портфеле
  - Сортировка по любой колонке
  - Визуализация доли секторов (pie chart или bar chart)

**API endpoints:**
- `GET /api/performance/visualization/returns` - данные для графика доходности
- `GET /api/performance/visualization/pnl-distribution` - распределение PnL
- `GET /api/performance/visualization/drawdown` - данные drawdown
- `GET /api/performance/visualization/heatmap` - данные для heatmap
- `GET /api/performance/sector-analysis` - секторный анализ
- `GET /api/performance/dashboard` - агрегированные данные для дашборда

**Файлы для создания:**
- `client/src/components/performance/PerformanceDashboard.tsx`
- `client/src/components/performance/PerformanceHeatmap.tsx`
- `client/src/components/performance/SectorAnalysis.tsx`
- `client/src/components/performance/PerformanceChart.tsx` (переиспользуемый компонент для графиков)
- `client/src/services/performanceApi.ts` (API клиент)

**Оценка времени:** 5-7 дней
