# План улучшений UX для фронтенд приложения

## 🎯 Цель
Сделать приложение максимально понятным и удобным даже для неопытных пользователей, чтобы они могли начать использовать систему без обучения.

---

## 📋 Категории улучшений

### 1. 🚀 Онбординг и первый запуск
**Приоритет: ВЫСОКИЙ**

#### 1.1 Приветственный экран при первом запуске
- [ ] Модальное окно "Добро пожаловать" с кратким описанием системы
- [ ] Кнопка "Начать быструю настройку" или "Пропустить"
- [ ] Сохранение флага "первый запуск" в localStorage

#### 1.2 Мастер быстрой настройки (Wizard)
- [ ] Пошаговый мастер настройки:
  1. Выбор режима торговли (Paper/Real)
  2. Настройка начального капитала
  3. Настройка Telegram уведомлений (опционально)
  4. Выбор стратегий для активации
  5. Завершение и переход на Dashboard
- [ ] Индикатор прогресса (шаг X из Y)
- [ ] Возможность вернуться к предыдущему шагу
- [ ] Кнопка "Пропустить" на каждом шаге

#### 1.3 Интерактивный тур по интерфейсу
- [ ] Компонент `OnboardingTour` с библиотекой (например, react-joyride)
- [ ] Тур по основным разделам:
  - Dashboard и его элементы
  - Навигация
  - Портфель
  - Рекомендации
  - Настройки
- [ ] Возможность запустить тур повторно из настроек
- [ ] Сохранение прогресса тура

### 2. 💡 Подсказки и контекстная помощь
**Приоритет: ВЫСОКИЙ**

#### 2.1 Tooltips с объяснениями
- [ ] Добавить tooltips ко всем важным элементам:
  - Иконки и кнопки
  - Метрики и показатели
  - Настройки и параметры
  - Статусы и индикаторы
- [ ] Компонент `Tooltip` с поддержкой:
  - Коротких подсказок (1-2 строки)
  - Расширенных подсказок с примерами
  - Ссылок на документацию

#### 2.2 Информационные карточки (Info Cards)
- [ ] Карточки с объяснениями на каждой странице:
  - "Что это?" - краткое описание раздела
  - "Как использовать?" - пошаговая инструкция
  - "Важно знать" - предупреждения и советы
- [ ] Возможность свернуть/развернуть карточки
- [ ] Кнопка "Больше не показывать" для опытных пользователей

#### 2.3 Контекстная справка
- [ ] Кнопка "?" рядом с каждым важным элементом
- [ ] Модальное окно с подробным объяснением
- [ ] Примеры использования
- [ ] Ссылки на документацию

#### 2.4 Подсказки при наведении на метрики
- [ ] При наведении на метрику показывать:
  - Что означает этот показатель
  - Как он рассчитывается
  - Нормальные значения
  - Что делать, если значение плохое

### 3. ⚠️ Улучшенная обработка ошибок и валидация
**Приоритет: ВЫСОКИЙ**

#### 3.1 Понятные сообщения об ошибках
- [ ] Заменить технические сообщения на понятные:
  - "Ошибка сети" → "Не удалось подключиться к серверу. Проверьте интернет."
  - "500 Internal Server Error" → "Произошла ошибка на сервере. Попробуйте позже."
- [ ] Предложения по решению проблемы
- [ ] Кнопка "Повторить попытку" для сетевых ошибок

#### 3.2 Валидация форм с подсказками
- [ ] Валидация в реальном времени
- [ ] Подсказки под полями:
  - "Минимальное значение: X"
  - "Максимальное значение: Y"
  - "Пример: ..."
- [ ] Визуальная индикация (зеленый/красный)
- [ ] Сообщения об ошибках рядом с полями

#### 3.3 Глобальный обработчик ошибок
- [ ] Компонент `ErrorBoundary` для отлова критических ошибок
- [ ] Страница "Что-то пошло не так" с:
  - Понятным сообщением
  - Кнопкой "Обновить страницу"
  - Кнопкой "Сообщить об ошибке"
  - Информацией для разработчиков (в режиме разработки)

#### 3.4 Предупреждения перед критическими действиями
- [ ] Модальные окна подтверждения для:
  - Переключения режима торговли
  - Удаления стратегий
  - Выполнения крупных сделок
  - Сброса настроек
- [ ] Четкое объяснение последствий
- [ ] Возможность отменить действие

## 📝 Технические детали

### Компоненты для создания
- `OnboardingWizard.tsx` - мастер настройки
- `OnboardingTour.tsx` - интерактивный тур
- `Tooltip.tsx` - улучшенные подсказки
- `InfoCard.tsx` - информационные карточки
- `ErrorBoundary.tsx` - обработка ошибок
- `StatusBar.tsx` - статус-бар
- `EmptyState.tsx` - пустые состояния
- `LoadingIndicator.tsx` - улучшенные индикаторы загрузки
- `ConfirmationModal.tsx` - модальные окна подтверждения
- `HelpButton.tsx` - кнопки помощи

### Библиотеки для использования
- `react-joyride` - для интерактивных туров
- `react-hot-toast` или улучшить существующий Toast
- `react-hook-form` - для валидации форм
- `framer-motion` - для анимаций (опционально)
