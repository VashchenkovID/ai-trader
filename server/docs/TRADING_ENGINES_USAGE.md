Пошаговые действия пользователя по режимам
Первый запуск приложения
Открыть приложение → главная страница (Dashboard)
Проверить статус системы:
WebSocket: должен быть "Онлайн"
Нейросети: статус загрузки моделей
Торговый движок: статус инициализации
Проверить кеш:
Время последнего обновления
До следующего обновления
Режим Paper (Бумажная торговля)
Начальная настройка
Перейти в "Режимы торговли" (/trading-mode)
Проверить текущий режим:
Должен быть PAPER (по умолчанию)
Если другой — переключить на Paper
Активация движка:
Статус: "Неактивен" → нажать "Активировать"
После переключения на Paper активируется автоматически
Проверить портфель:
Начальный капитал: 1,000,000₽ (виртуальный)
Позиции: могут быть демо-позиции
Обучение нейросетей (первый раз)
На Dashboard → "Управление нейросетями":
Нажать "Обучить все нейросети"
Дождаться завершения (может занять время)
Альтернатива: обучение через планировщик (автоматически по расписанию)
Ежедневная работа
Запуск анализа рынка:
На Dashboard → "Торговая сводка" → "Запустить анализ рынка"
Или автоматически по расписанию (если настроено)
Просмотр рекомендаций:
Перейти в "Торговые заявки" → вкладка "Рекомендации AI"
Просмотреть список рекомендаций BUY/SELL
Создание торговых заявок:
Выбрать рекомендацию → "Создать заявку"
Или массовое создание из нескольких рекомендаций
Подтверждение заявок:
Вкладка "Торговые заявки" → список заявок со статусом PENDING
Просмотреть детали (цена, количество, уверенность)
Нажать "Одобрить" или "Отклонить"
Исполнение заявок:
Если autoExecutionEnabled = true → исполнение автоматически после одобрения
Если false → вручную нажать "Исполнить" для заявок со статусом APPROVED
Мониторинг результатов:
"Портфель" → просмотр позиций и PnL
"Торговые заявки" → история исполненных заявок
Dashboard → статистика торговли (win rate, общая прибыль)
Что происходит автоматически
Обновление кеша данных (каждые 4 часа)
Обучение нейросетей (по расписанию, например ночью)
Анализ рынка (по расписанию или вручную)
Создание рекомендаций (после анализа)
Валидация ордеров (при исполнении)
Расчет PnL и статистики
Режим Micro (Микро-капитал)
Начальная настройка
Проверка готовности:
"Режимы торговли" → вкладка "Валидация"
Проверить критерии для перехода к Micro:
Минимум 2 прибыльных месяца
Win rate 55%+
Максимум 12% просадка
Минимум 50 сделок
Profit factor 1.3+
Коэффициент Шарпа 0.8+
Переключение режима:
Если критерии выполнены → статус "Доступен"
Нажать "Переключить" на карточке Micro
Подтвердить в диалоге
Активация движка:
После переключения движок деактивирован
Нажать "Активировать" (проверка доступности брокера)
Проверка подключения к брокеру:
Убедиться, что Tinkoff API настроен
Проверить доступность торговли
Ежедневная работа
Запуск анализа рынка (как в Paper)
Просмотр рекомендаций (как в Paper)
Создание заявок (как в Paper)
Подтверждение заявок (как в Paper, но с большей осторожностью)
Исполнение заявок:
Реальные ордера через Tinkoff API
Ограничение размера позиции: максимум 2% от капитала
Автоматическое уменьшение количества, если превышен лимит
Мониторинг:
Реальный портфель через Tinkoff API
Реальные сделки и комиссии
Строгий контроль просадки (максимум 5%)
Дополнительные действия
Регулярная проверка валидации:
"Режимы торговли" → "Валидация" → проверка готовности к Real режиму
Мониторинг рисков:
Dashboard → "Торговая сводка" → отслеживание просадки
При превышении лимитов → экстренная остановка

Начальная настройка
Проверка готовности:
"Режимы торговли" → "Валидация"
Проверить критерии для Real:
Минимум 3 прибыльных месяца
Win rate 60%+
Максимум 10% просадка
Минимум 100 сделок
Profit factor 1.5+
Коэффициент Шарпа 1.0+
Переключение режима:
Если критерии выполнены → статус "Доступен"
Нажать "Переключить" на карточке Real
Подтвердить (предупреждение о реальной торговле)
Активация движка:
Нажать "Активировать"
Проверка доступности брокера и торговли
Финальная проверка:
Убедиться, что все настройки корректны
Проверить лимиты риск-менеджмента
Ежедневная работа
Запуск анализа рынка (как в Paper/Micro)
Просмотр рекомендаций (как в Paper/Micro)
Создание заявок (как в Paper/Micro)
Подтверждение заявок:
Тщательная проверка каждой заявки
Высокая уверенность модели (минимум 0.8)
Исполнение заявок:
Реальные ордера через Tinkoff API
Ограничение размера позиции: максимум 1% от капитала
Максимально строгий контроль рисков
Мониторинг:
Реальный портфель

Отслеживание последовательных убытков

Важные моменты
Активация движка обязательна для всех режимов (кроме Paper, где активируется автоматически)
Валидация перед переключением режимов — система проверяет готовность
Подтверждение заявок — все заявки требуют подтверждения (если не включено автоисполнение)
Мониторинг рисков — регулярно проверять просадку и убытки
Режим Real требует особой осторожности — это реальные деньги
Система автоматизирует большую часть работы, но пользователь должен:
Подтверждать заявки
Мониторить риски
Принимать решения о переключении режимов
Контролировать общее состояние системы
