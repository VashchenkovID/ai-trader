# Система предсказаний с временными горизонтами

## Обзор

Система предсказаний использует **ансамбль из трех специализированных моделей**, каждая из которых анализирует разные временные горизонты:

### 🕐 Краткосрочный прогноз (1-3 дня)
- **Модель**: LSTM (Long Short-Term Memory)
- **Вес в ансамбле**: 40%
- **Фокус**: Внутридневные паттерны, быстрые движения цены
- **Использует**: Последние 24 часа данных
- **Применение**: Скальпинг, внутридневная торговля

### 📅 Среднесрочный прогноз (1-4 недели)
- **Модель**: CNN (Convolutional Neural Network)
- **Вес в ансамбле**: 35%
- **Фокус**: Графические паттерны, технические фигуры
- **Использует**: Последние 30 дней данных
- **Применение**: Свинг-трейдинг, среднесрочные позиции

### 📆 Долгосрочный прогноз (2-3 месяца)
- **Модель**: Transformer
- **Вес в ансамбле**: 25%
- **Фокус**: Контекстный анализ, фундаментальные тренды
- **Использует**: Последние 12 недель (84 дня) данных
- **Применение**: Инвестирование, долгосрочные позиции

## Интерпретация результатов

### Согласованность (Agreement)

- **> 0.7 (Высокая)**: Все три горизонта дают одинаковую рекомендацию
  - ✅ Надежный сигнал, можно действовать уверенно
- **0.5 - 0.7 (Умеренная)**: Горизонты частично расходятся
  - ⚠️ Сигнал требует осторожности, проверьте детали
- **< 0.5 (Низкая)**: Горизонты дают разные сигналы
  - ❌ Противоречивые сигналы, лучше воздержаться

### Рекомендации по горизонтам

#### Краткосрочный (1-3 дня)
- **BUY (score > 0.7)**: Ожидается рост в ближайшие дни
- **SELL (score < 0.3)**: Ожидается падение в ближайшие дни
- **HOLD (0.3-0.7)**: Боковое движение, неопределенность

#### Среднесрочный (1-4 недели)
- **BUY (score > 0.7)**: Формируется восходящий тренд
- **SELL (score < 0.3)**: Формируется нисходящий тренд
- **HOLD (0.3-0.7)**: Боковой тренд, консолидация

#### Долгосрочный (2-3 месяца)
- **BUY (score > 0.7)**: Позитивный фундаментальный тренд
- **SELL (score < 0.3)**: Негативный фундаментальный тренд
- **HOLD (0.3-0.7)**: Нейтральная долгосрочная динамика

## Стратегии использования

### 1. Скальпинг (внутридневная торговля)
**Фокус**: Краткосрочный горизонт
- Используйте сигналы LSTM (shortTerm)
- Игнорируйте долгосрочные сигналы
- Быстрые входы/выходы

### 2. Свинг-трейдинг (недели)
**Фокус**: Среднесрочный горизонт
- Используйте сигналы CNN (mediumTerm)
- Учитывайте краткосрочный для входа
- Позиции на 1-4 недели

### 3. Инвестирование (месяцы)
**Фокус**: Долгосрочный горизонт
- Используйте сигналы Transformer (longTerm)
- Учитывайте все горизонты для контекста
- Позиции на 2-3 месяца и более

### 4. Комплексная стратегия
**Фокус**: Все горизонты + согласованность
- Высокая согласованность (>0.7) + BUY = сильный сигнал на покупку
- Высокая согласованность (>0.7) + SELL = сильный сигнал на продажу
- Низкая согласованность (<0.5) = воздержаться от действий

## Примеры интерпретации

### Пример 1: Сильный сигнал на покупку
```javascript
{
  score: 0.82,
  confidence: 0.88,
  recommendation: "BUY",
  agreement: 0.92,  // Все горизонты согласны
  horizons: {
    shortTerm: { recommendation: "BUY", score: 0.85 },
    mediumTerm: { recommendation: "BUY", score: 0.80 },
    longTerm: { recommendation: "BUY", score: 0.78 }
  }
}
```
**Интерпретация**: Все три горизонта указывают на покупку с высокой уверенностью. Это сильный сигнал.

### Пример 2: Противоречивые сигналы
```javascript
{
  score: 0.55,
  confidence: 0.45,
  recommendation: "HOLD",
  agreement: 0.33,  // Горизонты расходятся
  horizons: {
    shortTerm: { recommendation: "BUY", score: 0.75 },
    mediumTerm: { recommendation: "HOLD", score: 0.50 },
    longTerm: { recommendation: "SELL", score: 0.25 }
  }
}
```
**Интерпретация**: Горизонты дают разные сигналы. Краткосрочно может быть рост, но долгосрочно падение. Лучше воздержаться.

### Пример 3: Среднесрочный тренд
```javascript
{
  score: 0.68,
  confidence: 0.72,
  recommendation: "BUY",
  agreement: 0.67,  // Умеренная согласованность
  horizons: {
    shortTerm: { recommendation: "HOLD", score: 0.55 },
    mediumTerm: { recommendation: "BUY", score: 0.75 },
    longTerm: { recommendation: "BUY", score: 0.70 }
  }
}
```
**Интерпретация**: Среднесрочный и долгосрочный горизонты указывают на покупку, краткосрочно нейтрально. Подходит для свинг-трейдинга.

## API Endpoints

### Получить предсказание с горизонтами
```http
POST /api/ensemble/predict
Content-Type: application/json

{
  "figi": "BBG004730N88",
  "portfolio": null
}
```

**Ответ**:
```json
{
  "success": true,
  "data": {
    "score": 0.75,
    "confidence": 0.82,
    "recommendation": "BUY",
    "agreement": 0.85,
    "horizons": { ... },
    "summary": "..."
  }
}
```

### Получить интегрированную рекомендацию
```http
POST /api/integrated-ai/recommendation
Content-Type: application/json

{
  "figi": "BBG004730N88",
  "portfolio": { ... }
}
```

**Ответ**: Включает рекомендации от всех активных моделей + горизонты от ансамбля

## Обновления системы

Система автоматически:
- ✅ Обновляет веса моделей на основе их производительности
- ✅ Рассчитывает согласованность между горизонтами
- ✅ Генерирует понятные объяснения для каждого горизонта
- ✅ Предоставляет структурированное резюме

## Обратная совместимость

Старые форматы ответов (`individualPredictions`, `weights`) сохранены для обратной совместимости. Новые поля (`horizons`, `agreement`, `summary`) добавляют дополнительную информацию без нарушения существующего функционала.
