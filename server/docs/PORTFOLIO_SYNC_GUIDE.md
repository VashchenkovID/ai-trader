# Руководство по синхронизации портфеля с Тинькофф

## Обзор

Система синхронизации портфеля позволяет автоматически получать данные о вашем инвестиционном портфеле из Тинькофф Инвестиций и обновлять их в приложении с заданным интервалом.

## Настройка

### 1. Получение токена Тинькофф

1. Зайдите в [Тинькофф Инвестиции](https://www.tinkoff.ru/invest/)
2. Перейдите в настройки → API
3. Создайте новый токен для торгового API
4. Скопируйте токен и ID счета

### 2. Настройка переменных окружения

Добавьте следующие переменные в файл `.env`:

```env
# Tinkoff API Configuration
TINKOFF_API_URL=https://invest-public-api.tinkoff.ru/rest
TINKOFF_TOKEN=your_tinkoff_token_here
TINKOFF_ACCOUNT_ID=your_account_id_here

# Portfolio Sync Configuration
PORTFOLIO_SYNC_ENABLED=true
PORTFOLIO_SYNC_INTERVAL=300000
PORTFOLIO_AUTO_UPDATE_PRICES=true
PORTFOLIO_SYNC_HISTORY=true
```

### 3. Переменные конфигурации

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TINKOFF_TOKEN` | Токен API Тинькофф | - |
| `TINKOFF_ACCOUNT_ID` | ID счета в Тинькофф | - |
| `PORTFOLIO_SYNC_ENABLED` | Включить синхронизацию | `false` |
| `PORTFOLIO_SYNC_INTERVAL` | Интервал синхронизации (мс) | `300000` (5 мин) |
| `PORTFOLIO_AUTO_UPDATE_PRICES` | Автообновление цен | `true` |
| `PORTFOLIO_SYNC_HISTORY` | Синхронизация истории | `true` |

## Использование

### 1. Через веб-интерфейс

1. Откройте страницу "Портфель"
2. Нажмите "Настройки синхронизации"
3. Настройте параметры синхронизации
4. Включите автоматическую синхронизацию

### 2. Через API

#### Получение статуса синхронизации
```bash
GET /api/portfolio-sync/status
```

#### Запуск ручной синхронизации
```bash
POST /api/portfolio-sync/sync
```

#### Настройка параметров
```bash
POST /api/portfolio-sync/settings
Content-Type: application/json

{
  "enabled": true,
  "interval": 300000,
  "accountId": "your_account_id",
  "autoUpdatePrices": true,
  "syncHistory": true
}
```

## Функции

### Автоматическая синхронизация

- Синхронизация запускается автоматически при старте сервера (если включена)
- Обновление данных по заданному интервалу
- Уведомления через WebSocket о статусе синхронизации

### Ручная синхронизация

- Возможность запустить синхронизацию вручную
- Принудительное обновление данных
- Мгновенное получение актуальной информации

### Управление настройками

- Включение/отключение синхронизации
- Настройка интервала обновления
- Выбор счета для синхронизации
- Настройка дополнительных параметров

## Данные, которые синхронизируются

### Портфель
- Общая стоимость портфеля
- Ожидаемая доходность
- Список позиций

### Позиции
- FIGI инструмента
- Тикер и название
- Количество
- Средняя цена покупки
- Текущая цена
- Ожидаемая доходность
- Вариационная маржа

### Операции
- История операций
- Статус операций
- Временные метки

## Мониторинг

### Статус синхронизации
- Время последней синхронизации
- Статус (активна/неактивна)
- Количество синхронизированных позиций
- Ошибки синхронизации

### Логи
- Детальные логи всех операций
- Ошибки и предупреждения
- Статистика производительности

## Устранение неполадок

### Ошибка аутентификации
- Проверьте правильность токена
- Убедитесь, что токен не истек
- Проверьте права доступа токена

### Ошибка доступа к счету
- Проверьте правильность ID счета
- Убедитесь, что токен имеет доступ к счету

### Проблемы с синхронизацией
- Проверьте подключение к интернету
- Проверьте статус API Тинькофф
- Посмотрите логи сервера

## Безопасность

- Токены хранятся в переменных окружения
- Все API запросы используют HTTPS
- Логи не содержат чувствительных данных
- Автоматическое обновление токенов при необходимости

## Ограничения API

- Лимиты запросов Тинькофф API
- Максимальный размер ответа
- Таймауты запросов
- Ограничения по частоте обновления

## Поддержка

При возникновении проблем:
1. Проверьте логи сервера
2. Убедитесь в правильности настроек
3. Проверьте статус API Тинькофф
4. Обратитесь к документации Тинькофф API
