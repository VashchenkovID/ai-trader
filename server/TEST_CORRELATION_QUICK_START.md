# Быстрый старт тестирования системы корреляций

## Шаг 1: Запуск миграции БД

```bash
cd server
node migrations/create-correlation-cache-table.js
```

## Шаг 2: Запуск быстрого теста

```bash
npm run test:correlation:quick
```

## Шаг 3: Запуск полного теста (опционально)

```bash
npm run test:correlation
```

## Что проверяют тесты

### Быстрый тест:
- ✅ Подключение к БД
- ✅ Инициализация сервисов
- ✅ Расчет корреляции между двумя инструментами
- ✅ Работа кеширования
- ✅ Создание матрицы корреляций
- ✅ Расчет корреляции портфеля

### Полный тест:
Все из быстрого теста +:
- ✅ Детальная проверка модели CorrelationCache
- ✅ Тестирование интеграции с RiskManagementService
- ✅ Тестирование интеграции с CapitalAllocationStrategy
- ✅ Проверка оценки корреляции инструмента
- ✅ Детальная статистика по всем тестам

## Требования

1. База данных PostgreSQL должна быть запущена
2. В `.env` файле должны быть настроены параметры БД
3. В кеше должны быть инструменты (минимум 2)
4. Для инструментов должны быть исторические свечи (минимум 20 дней)

## Если тесты не проходят

1. **Недостаточно инструментов**: Запустите сервер для обновления кеша
2. **Ошибка БД**: Проверьте подключение и настройки в `.env`
3. **Таблица не существует**: Запустите миграцию (Шаг 1)
4. **Недостаточно данных**: Подождите накопления исторических данных
