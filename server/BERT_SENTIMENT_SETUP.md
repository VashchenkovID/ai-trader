# Настройка анализа тональности

## Установка

```bash
cd server
npm install @xenova/transformers
```

## Описание

Система использует библиотеку `@xenova/transformers` для анализа тональности. Система автоматически пробует загрузить несколько моделей по порядку:

1. `Xenova/bert-base-multilingual-uncased-sentiment` - многоязычная модель от Xenova (лучшая для тональности, приоритет)
2. `Xenova/rubert-base-cased-sentiment` - ruBERT от DeepPavlov через Xenova (специализированная для русского)
3. `cointegrated/rubert-tiny2` - компактная русская модель
4. `nlptown/bert-base-multilingual-uncased-sentiment` - многоязычная модель
5. `Xenova/distilbert-base-multilingual-cased` - многоязычная модель от Xenova
6. Модель по умолчанию (английская, используется как fallback)

Система использует первую успешно загруженную модель. Модели от Xenova имеют приоритет, так как они специально подготовлены для библиотеки `@xenova/transformers`.

**Преимущества:**
- ✅ Специально обучена для анализа тональности на русском языке
- ✅ Высокая точность (использует предобученную BERT модель)
- ✅ Работает локально (не требует интернет после загрузки)
- ✅ Возвращает значение от -1 (отрицательное) до 1 (положительное)
- ✅ Использует квантованную версию модели для экономии памяти

## Как это работает

1. **Ленивая загрузка**: Модель загружается только при первом использовании
2. **Кеширование**: После загрузки модель остается в памяти
3. **Fallback**: Если модель не загрузилась, используется упрощенный метод на основе словарей

## Преобразование оценок

Модель по умолчанию для sentiment-analysis возвращает:
- **POSITIVE** (положительное) → значение от 0.2 до 1.0
- **NEGATIVE** (отрицательное) → значение от -1.0 до -0.2

Оценка confidence (score) влияет на интенсивность тональности:
- Высокий confidence (близко к 1.0) → более выраженная тональность
- Низкий confidence (близко к 0.5) → более нейтральная тональность

## Производительность

- **Первая загрузка**: ~30-60 секунд (загрузка модели из Hugging Face)
- **Последующие запуски**: Модель кешируется локально, загрузка быстрее
- **Анализ одного текста**: ~100-500ms (зависит от длины текста)
- **Использование памяти**: ~200-300MB (квантованная версия)

## Требования

- Node.js 16+
- @xenova/transformers (устанавливается автоматически)
- ~300MB свободной памяти для модели
- Интернет-соединение для первой загрузки модели

## Использование

Модель автоматически используется в методе `analyzeSentiment()` класса `NewsAnalysisService`.

Если модель не загрузилась, автоматически используется упрощенный метод на основе словарей.

## Пример использования

```javascript
const sentiment = await NewsAnalysisService.analyzeSentiment(
    "Акции компании показали отличные результаты в этом квартале!"
);
// Возвращает значение от -1 до 1, например: 0.85 (положительное)
```
