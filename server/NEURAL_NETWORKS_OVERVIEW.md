# Обзор нейросетей в системе AI Trader

## 🧠 Основные нейросети для торговли

### 1. **NeuralNetworkService** (Традиционная LSTM модель)
**Файл:** `server/src/services/NeuralNetworkService.js`

**Назначение:**
- Основная нейросеть для предсказания движения цен акций
- Использует LSTM (Long Short-Term Memory) архитектуру
- Работает с временными последовательностями данных

**Архитектура:**
- **Входной слой:** 25 фичей (цены, объемы, технические индикаторы, новости, Telegram настроения)
- **LSTM слои:** 128 → 64 единиц
- **Dense слои:** 128 → 64 → 32 единиц
- **Выходной слой:** 1 единица (вероятность роста цены)

**Что анализирует:**
- ✅ Цены и объемы торгов (5 + 5 фичей)
- ✅ Технические индикаторы: RSI, MACD, Bollinger Bands, SMA, EMA (6 фичей)
- ✅ Временные паттерны: час, день недели (2 фичи)
- ✅ Рыночные данные (3 фичи)
- ✅ **Новостные данные: сентимент и релевантность (2 фичи)**
- ✅ Telegram настроения (2 фичи)

**Когда используется:**
- Базовые предсказания для всех инструментов
- Быстрое обучение и предсказание
- Фолбэк при недоступности других моделей

---

### 2. **EnsembleService** (Ансамбль нейросетей)
**Файл:** `server/src/services/EnsembleService.js`

**Назначение:**
- Объединяет 3 специализированные модели для более точных предсказаний
- Каждая модель анализирует разные временные горизонты
- Финальное решение принимается взвешенным голосованием

**Состав ансамбля:**

#### 2.1. **Short-term LSTM** (40% веса)
- **Горизонт:** 24 часа (внутридневная торговля)
- **Архитектура:** LSTM (128 → 64) + Dense слои
- **Специализация:** Краткосрочные паттерны, внутридневные движения
- **Когда эффективна:** Скальпинг, быстрые сделки

#### 2.2. **Medium-term CNN** (35% веса)
- **Горизонт:** 30 дней (среднесрочная торговля)
- **Архитектура:** Conv1D (32 → 64 фильтров) + Dense слои
- **Специализация:** Графические паттерны, тренды
- **Когда эффективна:** Свинг-трейдинг, среднесрочные позиции

#### 2.3. **Long-term Transformer** (25% веса)
- **Горизонт:** 12 недель (долгосрочный анализ)
- **Архитектура:** Transformer с attention механизмом
- **Специализация:** Контекстный анализ, долгосрочные тренды
- **Когда эффективна:** Инвестиционные решения, долгосрочные позиции

**Как работает:**
1. Каждая модель делает свое предсказание
2. Результаты взвешиваются по весам (40%, 35%, 25%)
3. Финальная рекомендация = взвешенная сумма всех предсказаний

**Преимущества:**
- ✅ Более высокая точность за счет комбинации разных подходов
- ✅ Устойчивость к ошибкам одной модели
- ✅ Адаптация к разным временным горизонтам

### 3. **MetaLearningService** (Мета-обучение)
**Файл:** `server/src/services/MetaLearningService.js`

**Назначение:**
- Быстрая адаптация моделей к новым рыночным условиям
- Использование опыта из похожих ситуаций
- "Обучение обучению" - модель учится быстро адаптироваться

**Как работает:**
1. **База знаний:** Сохраняет опыт предыдущих задач (рыночные условия + результаты)
2. **Поиск похожих задач:** Находит похожие ситуации из прошлого
3. **Быстрая адаптация:** Применяет успешные стратегии из похожих ситуаций
4. **Обновление знаний:** Сохраняет новый опыт для будущего использования

**Что анализирует:**
- Рыночные условия (волатильность, тренд, объемы)
- Тип задачи (предсказание цены, управление рисками и т.д.)
- Производительность предыдущих решений
- Контекст задачи (64-мерный embedding)

**Когда используется:**
- При изменении рыночных условий
- Для новых инструментов
- При адаптации к новым стратегиям
- Для улучшения существующих моделей

**Преимущества:**
- ✅ Быстрая адаптация (не нужно полное переобучение)
- ✅ Использование накопленного опыта
- ✅ Эффективность на малых данных

---

### 4. **ReinforcementLearningService** (Обучение с подкреплением)
**Файл:** `server/src/services/ReinforcementLearningService.js`

**Назначение:**
- Обучение торговым стратегиям через взаимодействие с рынком
- Использует Deep Q-Network (DQN) алгоритм
- Учится на собственных действиях и их результатах

**Как работает:**
1. **Агент** (нейросеть) выбирает действие: купить, продать, держать
2. **Окружение** (рынок) возвращает награду (прибыль/убыток)
3. **Обучение:** Агент учится максимизировать награду
4. **Память:** Сохраняет опыт (состояние → действие → награда)

**Архитектура:**
- **Вход:** 20 фичей (состояние рынка)
- **Выход:** 3 действия (купить, продать, держать)
- **Алгоритм:** DQN с приоритетным replay buffer

**Что анализирует:**
- Текущее состояние портфеля
- Рыночные данные (цены, объемы, индикаторы)
- Исторические результаты действий
- Риск-награда соотношение

**Когда используется:**
- Для оптимизации торговых стратегий
- При обучении на реальных данных
- Для адаптации к изменяющимся условиям
- Для поиска оптимальных точек входа/выхода

**Преимущества:**
- ✅ Учится на реальных результатах
- ✅ Адаптируется к конкретным условиям
- ✅ Оптимизирует стратегию автоматически

---

### 5. **IntegratedAIService** (Интегрированный сервис)
**Файл:** `server/src/services/IntegratedAIService.js`

**Назначение:**
- Объединяет все нейросети в единую систему
- Принимает финальные решения на основе всех моделей
- Управляет активацией/деактивацией моделей

**Как работает:**
1. Получает рекомендации от всех активных моделей:
   - Ensemble (ансамбль)
   - Traditional (LSTM)
   - Reinforcement Learning
   - Meta-Learning (адаптация)
2. Взвешивает рекомендации по производительности каждой модели
3. Выдает финальную интегрированную рекомендацию
4. Отправляет сильные сигналы в Telegram

**Логика взвешивания:**
- Веса зависят от точности каждой модели
- Более точные модели получают больший вес
- Meta-Learning корректирует веса на основе похожих задач

**Преимущества:**
- ✅ Максимальная точность за счет комбинации всех подходов
- ✅ Устойчивость к ошибкам отдельных моделей
- ✅ Автоматическое управление всеми моделями

## 🔍 Вспомогательные инструменты

### 6. **BERT модель для анализа тональности** (NewsAnalysisService)
**Модель:** `@nlptown/bert-base-multilingual-uncased-sentiment`

**Назначение:**
- Анализ тональности новостей (положительная/отрицательная)
- Поддержка русского языка
- Используется для создания новостных фичей

**Как используется:**
- Анализирует текст новостей
- Возвращает оценку от -1 (отрицательная) до +1 (положительная)
- Результат используется как фича в основной LSTM модели

**Важно:** Это не отдельная нейросеть для торговли, а инструмент для анализа текста.

## 🎯 Когда использовать какую модель?

### Для быстрых предсказаний:
→ **NeuralNetworkService** (традиционная LSTM)

### Для максимальной точности:
→ **EnsembleService** (ансамбль всех моделей)

### При изменении рынка:
→ **MetaLearningService** (быстрая адаптация)

### Для оптимизации стратегии:
→ **ReinforcementLearningService** (обучение на опыте)

### Для финальных решений:
→ **IntegratedAIService** (объединяет все)

## 📝 Итог

В системе используется **5 основных нейросетей** для торговли:

1. **NeuralNetworkService** - базовая LSTM модель
2. **EnsembleService** - ансамбль из 3 специализированных моделей
3. **MetaLearningService** - быстрая адаптация к новым условиям
4. **ReinforcementLearningService** - обучение торговым стратегиям
5. **IntegratedAIService** - объединяет все модели

Все они работают вместе для максимально точных торговых рекомендаций! 🚀
