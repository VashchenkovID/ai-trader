# Тестирование функциональности скачивания и загрузки бэкапов

## Предварительные требования

Перед запуском тестов необходимо установить зависимости:

```bash
cd server
npm install archiver yauzl
```

## Запуск тестов

```bash
npm run test:backup
```

или напрямую:

```bash
node test-backup.js
```

## Что тестируется

1. **Проверка зависимостей** - наличие библиотек `archiver` и `yauzl`
2. **Инициализация BackupService** - проверка инициализации сервиса
3. **Проверка директорий** - наличие необходимых директорий для бэкапов
4. **Создание бэкапа** - тест создания полного бэкапа
5. **Скачивание бэкапа** - создание ZIP архива из бэкапа
6. **Загрузка бэкапа** - распаковка ZIP архива
7. **Очистка** - удаление тестовых файлов

## API Endpoints для тестирования

### Скачать бэкап
```bash
GET /api/backup/:id/download
```

Пример:
```bash
curl -O http://localhost:3001/api/backup/full_2024-01-24T12-00-00-000Z/download
```

### Загрузить бэкап
```bash
POST /api/backup/upload
Content-Type: multipart/form-data
```

Пример с curl:
```bash
curl -X POST \
  http://localhost:3001/api/backup/upload \
  -F "file=@backup_full_2024-01-24T12-00-00-000Z_2024-01-24T12-30-00-000Z.zip" \
  -F "restore=true" \
  -F "components[]=database" \
  -F "components[]=settings"
```

## Ожидаемый результат

При успешном тестировании вы увидите:
- ✅ Все проверки пройдены
- ✅ Бэкап создан
- ✅ ZIP архив создан с информацией о размере и сжатии
- ✅ ZIP архив распакован
- ✅ Тестовые файлы удалены

## Возможные проблемы

1. **Библиотеки не установлены**
   - Решение: `npm install archiver yauzl`

2. **BackupService не инициализирован**
   - Решение: Убедитесь, что база данных подключена и сервисы инициализированы

3. **Недостаточно места на диске**
   - Решение: Освободите место в директории `server/backups/`

4. **Ошибки прав доступа**
   - Решение: Проверьте права на запись в директорию `server/backups/`
