# Тестирование нового функционала обучения

Этот скрипт проверяет все реализованные улучшения системы обучения.

## Что тестируется:

1. ✅ **Проверка качества данных** - валидация фичей и меток
2. ✅ **Адаптивные параметры обучения** - автоматическая подстройка epochs, batchSize, learningRate
3. ✅ **Feature Engineering** - проверка размера фичей (70 фичей)
4. ✅ **Обнаружение дрейфа данных** - сравнение текущего и базового распределения
5. ✅ **SMOTE для балансировки классов** - генерация синтетических образцов
6. ✅ **Обучение с новым функционалом** - полный цикл обучения (быстрый тест)
7. ✅ **Версионирование моделей** - проверка сохранения метаданных
8. ✅ **Загрузка сохраненных гиперпараметров** - проверка оптимизации

## Запуск теста:

### Вариант 1: Прямой запуск
```bash
cd server
node tests/test-new-training-features.js
```

### Вариант 2: Через npm script (если добавлен)
```bash
cd server
npm run test:new-features
```

## Требования:

- Node.js 18+ (с поддержкой ES modules)
- Инициализированная база данных
- Доступные инструменты в кеше (минимум 1 инструмент)
- Достаточно данных для обучения (минимум 50 свечей)

## Ожидаемое время выполнения:

- **Быстрый тест:** 2-5 минут (с обучением на 5 эпохах)
- **Полный тест:** 10-30 минут (зависит от количества данных)

## Что проверяется:

### 1. Проверка качества данных
- Валидность фичей (нет NaN, Infinity)
- Размер фичей (должно быть 70)
- Дисбаланс классов
- Минимальное количество данных

### 2. Адаптивные параметры
- Автоматический расчет epochs на основе размера данных
- Адаптивный batch size
- Адаптивный learning rate на основе волатильности

### 3. Feature Engineering
- Проверка размера фичей (70 вместо 64)
- Новые фичи: взаимодействия, тренд, волатильность

### 4. Обнаружение дрейфа данных
- Сравнение распределения фичей
- Расчет дрейф-скора
- Определение серьезности дрейфа

### 5. SMOTE
- Автоматическое применение при дисбалансе >70%
- Генерация синтетических образцов
- Балансировка классов

### 6. Обучение
- Полный цикл обучения с новым функционалом
- Проверка метрик (F1-score, Accuracy, Precision, Recall, AUC)
- Проверка Direction Accuracy

### 7. Версионирование
- Сохранение метаданных модели
- История версий
- Параметры обучения

### 8. Гиперпараметры
- Загрузка сохраненных параметров
- Использование оптимизированных значений

## Интерпретация результатов:

### ✅ Успешные тесты:
- Все проверки пройдены
- Обучение завершено успешно
- Метрики в разумных пределах (F1-score: 0.5-0.8)

### ⚠️ Предупреждения:
- Недостаточно данных для некоторых тестов (это нормально)
- Метаданные не найдены (нормально для первого обучения)
- Сохраненные параметры не найдены (нормально, если оптимизация еще не выполнялась)

### ❌ Ошибки:
- Критические проблемы с данными
- Ошибки при обучении
- Проблемы с доступом к сервисам

## Устранение проблем:

### Ошибка: "Нет доступных инструментов"
- Убедитесь, что база данных инициализирована
- Проверьте, что в кеше есть инструменты
- Запустите обновление кеша: `POST /api/system/cache/full-update`

### Ошибка: "Недостаточно данных"
- Убедитесь, что есть свечи для инструмента (минимум 50)
- Проверьте, что данные актуальны
- Запустите обновление свечей

### Ошибка при обучении:
- Проверьте логи на наличие детальной информации
- Убедитесь, что достаточно памяти
- Попробуйте уменьшить количество эпох в тесте
