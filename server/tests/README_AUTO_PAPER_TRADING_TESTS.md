# Тесты для автоматической торговли в paper режиме

## Описание

Тесты проверяют функциональность автоматической торговли в paper режиме, включая:
- RealisticExecutionSimulator
- AutoPaperTradingService
- AutoPaperTradingStats модель
- Новые поля в TradingRequest
- Валидацию настроек

## Запуск тестов

```bash
cd server
npm run test:auto-paper-trading
```

Или напрямую:

```bash
cd server
node tests/test-auto-paper-trading.js
```

## Требования

Перед запуском тестов убедитесь, что:
1. База данных настроена и доступна
2. Миграции выполнены (см. `migrations/README_AUTO_PAPER_TRADING.md`)
3. Переменные окружения настроены в `.env`

## Тесты

### 1. RealisticExecutionSimulator
- Проверяет инициализацию сервиса
- Тестирует симуляцию исполнения ордеров
- Проверяет расчет спредов, проскальзывания и комиссий

### 2. AutoPaperTradingService - Инициализация
- Проверяет инициализацию сервиса
- Проверяет загрузку статистики из БД
- Проверяет корректность начальных настроек

### 3. canAutoExecute
- Проверяет логику определения возможности автоматического исполнения
- Тестирует различные условия (режим торговли, лимиты, confidence и т.д.)

### 4. AutoPaperTradingStats
- Проверяет создание и получение статистики
- Тестирует методы модели

### 5. Новые поля в TradingRequest
- Проверяет наличие новых полей
- Тестирует сохранение и загрузку значений

### 6. Валидация настроек
- Проверяет валидацию валидных настроек
- Тестирует отклонение невалидных настроек

## Результаты

Тесты выводят результаты в консоль:
- ✅ - тест пройден
- ❌ - тест провален
- 📊 - информация о тесте

В конце выводится общая статистика: `X/Y пройдено`

## Устранение проблем

### Ошибка подключения к БД
Убедитесь, что переменные окружения настроены:
- `DB_NAME`
- `DB_USER`
- `DB_PASSWORD`
- `DB_HOST`
- `DB_PORT`

### Ошибка "таблица не существует"
Выполните миграции перед запуском тестов:
```bash
npm run migrate:auto-paper-trading
```

### Ошибка "режим торговли не paper"
Тесты автоматически переключают режим на paper, но если это не работает, проверьте настройки TradingModeManager.
