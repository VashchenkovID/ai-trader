# 📊 Мониторинг производительности в реальном времени

## 🎯 Обзор системы

Система мониторинга производительности в реальном времени обеспечивает непрерывное отслеживание всех аспектов работы нейросети и торговой системы. Она включает:

- **Мониторинг обучения** - отслеживание пайплайнов, точности, прогресса
- **Мониторинг бэктестинга** - доходность, коэффициент Шарпа, лучшие/худшие исполнители
- **Мониторинг оценки** - общие баллы моделей, статистика оценок
- **Системный мониторинг** - память, CPU, время ответа, ошибки
- **Система алертов** - уведомления о критических проблемах
- **WebSocket трансляция** - обновления в реальном времени

## 📊 Типы метрик

### 1. Метрики обучения
- **Активные пайплайны**: Количество текущих процессов обучения
- **Завершенные пайплайны**: Общее количество успешных пайплайнов
- **Неудачные пайплайны**: Общее количество неудачных пайплайнов
- **Средняя точность**: Средняя точность по всем пайплайнам
- **Средняя длительность**: Среднее время выполнения пайплайна
- **Текущий этап**: Название текущего этапа обучения
- **Прогресс**: Процент выполнения текущего этапа (0-100%)

### 2. Метрики бэктестинга
- **Активные бэктесты**: Количество текущих бэктестов
- **Завершенные бэктесты**: Общее количество успешных бэктестов
- **Неудачные бэктесты**: Общее количество неудачных бэктестов
- **Средняя доходность**: Средняя доходность по всем бэктестам
- **Средний коэффициент Шарпа**: Средний коэффициент Шарпа
- **Лучший исполнитель**: FIGI инструмента с лучшей доходностью
- **Худший исполнитель**: FIGI инструмента с худшей доходностью

### 3. Метрики оценки
- **Общее количество оценок**: Всего проведенных оценок моделей
- **Средний балл**: Средний общий балл моделей (0-100)
- **Высокобалльные модели**: Количество моделей с баллом > 80
- **Низкобалльные модели**: Количество моделей с баллом < 50
- **Последняя оценка**: Данные о последней проведенной оценке

### 4. Системные метрики
- **Использование памяти**: Текущее использование памяти в MB
- **Использование CPU**: Текущее использование CPU в миллисекундах
- **Активные соединения**: Количество активных WebSocket соединений
- **Время ответа**: Среднее время ответа на запросы в миллисекундах
- **Процент ошибок**: Процент запросов, завершившихся с ошибкой

## 🚨 Система алертов

### Типы алертов
- **error**: Критические проблемы, требующие немедленного внимания
- **warning**: Предупреждения о потенциальных проблемах
- **info**: Информационные сообщения

### Категории алертов
- **training**: Проблемы с обучением нейросети
- **backtesting**: Проблемы с бэктестингом
- **evaluation**: Проблемы с оценкой моделей
- **system**: Системные проблемы

### Примеры алертов
```javascript
{
  "type": "warning",
  "category": "training",
  "message": "Low training accuracy: 45.2%",
  "value": 0.452,
  "threshold": 0.6,
  "timestamp": "2024-01-15T10:30:00Z"
}

{
  "type": "error",
  "category": "system",
  "message": "High response time: 8500ms",
  "value": 8500,
  "threshold": 5000,
  "timestamp": "2024-01-15T10:35:00Z"
}
```

## 📈 WebSocket трансляция

### Типы сообщений
```javascript
// Обновление метрик
{
  "type": "performance_metrics",
  "data": {
    "training": { ... },
    "backtesting": { ... },
    "evaluation": { ... },
    "system": { ... },
    "alerts": [ ... ],
    "timestamp": "2024-01-15T10:30:00Z",
    "isMonitoring": true
  }
}

// Алерт
{
  "type": "alert",
  "data": {
    "type": "warning",
    "category": "training",
    "message": "Low training accuracy",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}
```

### Подключение к WebSocket
```javascript
const ws = new WebSocket('ws://localhost:3001/');
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'performance_metrics') {
    updateDashboard(data.data);
  }
};
```

## 🎛️ Дашборд мониторинга

### Основные секции
1. **System Health** - Общее состояние системы
2. **Training** - Метрики обучения нейросети
3. **Backtesting** - Метрики бэктестинга
4. **Evaluation** - Метрики оценки моделей
5. **Progress Bars** - Прогресс текущих операций
6. **Alerts** - Список активных алертов
7. **System Metrics** - Детальные системные метрики

### Функции дашборда
- **Автообновление** каждые 30 секунд
- **Ручное обновление** по кнопке
- **Запуск/остановка** мониторинга
- **Очистка алертов**
- **Экспорт данных**

## 🔧 Настройка и конфигурация

### Пороговые значения по умолчанию
```javascript
const defaultThresholds = {
  accuracy: 0.6,        // 60% точность
  return: 10,           // 10% доходность
  sharpe: 1.0,          // Коэффициент Шарпа 1.0
  drawdown: 15,         // 15% максимальная просадка
  responseTime: 5000,   // 5 секунд время ответа
  errorRate: 5          // 5% процент ошибок
};
```

### Интервал мониторинга
- **Сбор метрик**: каждые 30 секунд
- **Проверка алертов**: каждые 30 секунд
- **Трансляция WebSocket**: каждые 30 секунд
- **Очистка старых алертов**: каждые 30 секунд (алерты старше 1 часа)

### История данных
- **Максимальный размер истории**: 1000 записей
- **Автоматическая очистка**: старые записи удаляются
- **Экспорт**: полная история в JSON формате
