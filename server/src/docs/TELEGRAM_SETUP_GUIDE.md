# 📱 Руководство по настройке Telegram Sentiment Service

## 🎯 **Что мы настроили:**

✅ **TelegramSentimentService** - Полностью настроен для работы с реальными данными

## 🚀 **Быстрый старт:**

### **1. Минимальная настройка (только Bot Token):**

```bash
# В .env файле добавьте:
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
```

**Что получите:**
- ✅ Базовый доступ к Telegram API
- ✅ Мониторинг каналов, где бот добавлен
- ✅ Поиск по ключевым словам
- ✅ Fallback на моковые данные при ошибках

### **2. Полная настройка (Bot Token + API ID + Hash):**

```bash
# В .env файле добавьте:
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
```

**Что получите:**
- ✅ Полный доступ к Telegram API
- ✅ Мониторинг всех каналов
- ✅ Расширенные возможности поиска
- ✅ Максимальная функциональность

## 📋 **Пошаговая настройка:**

### **Шаг 1: Получение Bot Token**

1. **Откройте Telegram** и найдите `@BotFather`
2. **Отправьте команду** `/newbot`
3. **Введите название бота:** `Trading Helper Bot`
4. **Введите username:** `trading_helper_bot`
5. **Скопируйте токен** (формат: `123456789:ABCdef...`)
6. **Добавьте в .env файл:**
   ```bash
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь
   ```

### **Шаг 2: Получение API ID и Hash (опционально)**

1. **Перейдите на** https://my.telegram.org
2. **Войдите в свой аккаунт** Telegram
3. **Перейдите в** "API development tools"
4. **Создайте приложение:**
   - **App title:** Trading Helper
   - **Short name:** trading_helper
   - **Platform:** Desktop
5. **Скопируйте API ID и Hash**
6. **Добавьте в .env файл:**
   ```bash
   TELEGRAM_API_ID=ваш_api_id
   TELEGRAM_API_HASH=ваш_api_hash
   ```

### **Шаг 3: Настройка каналов**

1. **Добавьте бота в нужные каналы** как администратора
2. **Используйте API для добавления каналов:**
   ```bash
   POST /api/telegram/channels
   {
     "channel": "@tinkoff_invest"
   }
   ```

## 🔧 **API методы:**

### **Анализ сентимента:**
```javascript
const analysis = await TelegramSentimentService.analyzeTelegramSentiment(figi, {
  days: 7,
  limit: 50
});
```

### **Управление каналами:**
```javascript
// Добавить канал
TelegramSentimentService.addChannel('@tinkoff_invest');

// Удалить канал
TelegramSentimentService.removeChannel('@tinkoff_invest');

// Получить список каналов

```

### **Проверка доступности:**
```javascript
// Проверить канал

// Проверить все каналы
const allStatus = await TelegramSentimentService.checkAllChannelsAvailability();
```
