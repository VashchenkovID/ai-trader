# 🎯 Рекомендуемые интервалы обучения - Применено

## 📋 Что было изменено

### 1. **Обновлены настройки по умолчанию в Settings.js**

#### Планировщик (Scheduler)
```javascript
// БЫЛО → СТАЛО
cache_update_interval: '0 */6 * * *' → '0 */4 * * *'  // Каждые 6 часов → каждые 4 часа
analysis_interval: '0 */2 * * *' → '0 */1 * * *'      // Каждые 2 часа → каждый час
nn_training_interval: '*/15 * * * *' → '*/30 * * * *' // Каждые 15 минут → каждые 30 минут
nn_quick_training_limit: 10 → 15                      // 10 инструментов → 15 инструментов
```

#### Нейросеть (Neural Network)
```javascript
// Добавлены новые настройки:
nn_learning_rate: 0.0005          // Learning rate
nn_batch_size: 16                 // Размер батча
nn_epochs: 50                     // Количество эпох
nn_dropout_rate: 0.2              // Коэффициент dropout
nn_validation_split: 0.2          // Доля валидации
nn_early_stopping_patience: 10    // Терпение для early stopping
nn_training_strategy: 'progressive' // Стратегия обучения
nn_sequence_length: 60            // Длина последовательности LSTM
nn_prediction_horizon: 5          // Горизонт предсказания
nn_accuracy_threshold: 0.65       // Минимальная точность
```

### 2. **Обновлен SchedulerService.js**
- Использует новые значения по умолчанию
- Кеш обновляется каждые 4 часа
- Анализ рынка каждый час
- Быстрое обучение каждые 30 минут

### 3. **Обновлен NeuralNetworkService.js**
- `createModel()` теперь асинхронный и использует настройки из БД
- `trainForInstrument()` использует настраиваемые параметры обучения
- Поддержка всех новых гиперпараметров

### 4. **Созданы новые сервисы**

#### TrainingOptimizationService.js
- 5 стратегий обучения: Progressive, Ensemble, Adaptive, Transfer, Reinforcement
- Автоматический выбор оптимальной стратегии
- Расширенная подготовка данных
- Временные признаки и рыночный контекст

#### TrainingRecommendations.js
- Персональные рекомендации на основе анализа системы
- Анализ качества данных, рыночных условий, производительности
- Адаптивные настройки под российский рынок

#### ApplyRecommendedSettings.js
- Автоматическое применение рекомендуемых настроек
- Сравнение текущих и рекомендуемых настроек
- Сброс к значениям по умолчанию

### 5. **Создан API для оптимизации обучения**

#### Новые endpoints:
```
GET  /api/training-optimization/recommendations     - Получить рекомендации
POST /api/training-optimization/apply-settings      - Применить настройки
POST /api/training-optimization/reset-settings      - Сбросить к умолчанию
GET  /api/training-optimization/current-settings    - Текущие настройки
GET  /api/training-optimization/compare             - Сравнить с рекомендациями
POST /api/training-optimization/train-optimal       - Обучение с оптимальной стратегией
GET  /api/training-optimization/training-stats      - Статистика обучения
POST /api/training-optimization/analyze-system      - Анализ системы
```

## 🚀 Как использовать

### 1. **Автоматическое применение настроек**
```bash
cd server
node src/utils/applyRecommendedIntervals.js
```

### 2. **Через API**
```javascript
// Получить рекомендации
const response = await fetch('/api/training-optimization/recommendations');
const recommendations = await response.json();

// Применить настройки
await fetch('/api/training-optimization/apply-settings', {
    method: 'POST'
});
```

### 3. **Через настройки в UI**
- Перейдите в раздел "Настройки"
- Выберите категорию "Нейросеть"
- Настройте параметры согласно рекомендациям
