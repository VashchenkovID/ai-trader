# 📊 Система оценки нейросети - Полное руководство

## 🎯 Обзор системы

Новая система оценки нейросети реализует ваш план по структурированному обучению и комплексной оценке модели. Система включает:

- **Финансовые метрики** (Sharpe Ratio, Max Drawdown, Win Rate, etc.)
- **Статистические метрики** (Precision, Recall, F1-Score, AUC-ROC)
- **Метрики стабильности** (Monthly Consistency, Drawdown Duration)
- **Правильное разделение данных** по временным периодам
- **Структурированный пайплайн обучения** по этапам
- **Продвинутый бэктестинг** с реальными торговыми условиями

## 🏗️ Архитектура системы

### 1. EvaluationMetricsService
```javascript
// Основные финансовые метрики
- calculateTotalReturn()      // Общая доходность
- calculateSharpeRatio()      // Коэффициент Шарпа (>1.2)
- calculateMaxDrawdown()      // Максимальная просадка (<15%)
- calculateWinRate()          // Процент прибыльных сделок (>55%)
- calculateProfitFactor()     // Profit Factor (>1.5)
- calculateCalmarRatio()      // Коэффициент Калмара (>0.5)

// Статистические метрики ИИ
- calculateConfusionMatrix()  // Матрица ошибок
- calculatePrecision()        // Точность (>0.6)
- calculateRecall()           // Полнота (>0.6)
- calculateF1Score()          // F1-Score (>0.6)
- calculateAUCROC()           // AUC-ROC (>0.7)

// Метрики стабильности
- calculateMonthlyConsistency() // Консистентность по месяцам
- calculateDrawdownDuration()   // Длительность просадок
- calculateVolatility()         // Волатильность доходности
```

### 2. DataSplittingService
```javascript
// Правильное разделение данных по времени
- getTrainingData()     // 2021-2022 (обучение)
- getValidationData()   // 2023, первые 6 месяцев (валидация)
- getTestData()         // 2023, вторые 6 месяцев (тестирование)
- getFinalTestData()    // 2024 (финальное тестирование)

// Проверка качества данных
- validateDataSplit()   // Проверка на пересечения и достаточность
- createTimeWindows()   // Создание временных окон
- createBalancedDataset() // Балансировка классов
```

### 3. StructuredTrainingPipeline
```javascript
// Этапное обучение по вашему плану
- runFullPipeline()     // Полный пайплайн
- runStage1()           // Базовые фичи (цена, объем)
- runStage2()           // Технические индикаторы
- runStage3()           // Оптимизация гиперпараметров
- runStage4()           // Финальная валидация
```

### 4. BacktestService (улучшенный)
```javascript
// Продвинутый бэктестинг
- runComprehensiveBacktest()    // Полный бэктест с метриками
- runComparativeBacktest()      // Сравнительный анализ
- calculateFinancialMetrics()   // Финансовые метрики
- calculateStatisticalMetrics() // Статистические метрики
```

## 🚀 Использование системы

### 1. Запуск полного пайплайна обучения

```javascript

    "predictionHorizon": 5
  }

```

### 2. Запуск бэктеста

```javascript

{
```

## 📈 Критерии успеха

### Финансовые метрики (цели)
- **Sharpe Ratio**: > 1.2
- **Max Drawdown**: < 15%
- **Win Rate**: > 55%
- **Profit Factor**: > 1.5
- **Calmar Ratio**: > 0.5

### Статистические метрики (цели)
- **Precision**: > 0.6
- **Recall**: > 0.6
- **F1-Score**: > 0.6
- **AUC-ROC**: > 0.7

### Метрики стабильности (цели)
- **Monthly Consistency**: 100% (не более 2 убыточных месяцев подряд)
- **Drawdown Duration**: < 30 дней
- **Volatility**: < 20%

## 🎯 Этапы обучения

### Этап 1: Базовое обучение (1 неделя)
- **Данные**: 2021-2022
- **Фичи**: Цена, объем
- **Цель**: Стабильная работа на базовых данных

### Этап 2: Технические индикаторы (1 неделя)
- **Данные**: 2021-2022
- **Фичи**: Цена, объем + технические индикаторы
- **Цель**: Улучшение точности предсказаний

### Этап 3: Оптимизация (1 неделя)
- **Данные**: 2021-2022
- **Фичи**: Все доступные + временные
- **Цель**: Оптимальные гиперпараметры

### Этап 4: Валидация (1 неделя)
- **Данные**: 2023, первые 6 месяцев
- **Цель**: Проверка на неизвестных данных

### Этап 5: Финальное тестирование (1 неделя)
- **Данные**: 2024 (НИКОГДА не использовались)
- **Цель**: Финальная проверка перед продакшеном
