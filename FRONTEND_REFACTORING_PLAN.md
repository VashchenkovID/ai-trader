# 📋 План рефакторинга фронтенда

## 🎯 Цель
Создать простой и понятный интерфейс для обычного пользователя, скрыв технические детали в отдельные разделы.

---

## 📊 Анализ текущих страниц

### ✅ ПОЛЬЗОВАТЕЛЬСКИЕ страницы (для обычного пользователя)

#### 1. **Dashboard (Главная)** - ✅ ОСТАВИТЬ, УЛУЧШИТЬ
- **Назначение:** Главный экран с ключевыми метриками
- **Что показывать:**
  - Текущая стоимость портфеля
  - Прибыль/убыток за день/неделю/месяц
  - Топ-3 рекомендации к покупке
  - Статус обучения (простой индикатор: "Система работает" / "Обучение...")
  - Последние сделки (3-5 штук)
- **Упрощения:**
  - Убрать технические детали (статусы нейросетей, метрики производительности)
  - Большие понятные карточки с числами
  - Простые индикаторы (зеленый/красный/желтый)
- **WebSocket:** `trading_stats_update`, `training_status_update` (упрощенный)

#### 2. **Portfolio (Портфель)** - ✅ ОСТАВИТЬ, УЛУЧШИТЬ
- **Назначение:** Просмотр текущих позиций и истории
- **Что показывать:**
  - Текущие позиции с прибылью/убытком
  - История сделок
  - График изменения стоимости портфеля
  - Распределение по секторам (визуализация)
- **Упрощения:**
  - Убрать технические метрики (Sharpe Ratio, корреляции)
  - Простые фильтры (по инструменту, по дате)
- **WebSocket:** `trading_stats_update`, `portfolio_updates`

#### 3. **Recommendations (Рекомендации)** - ✅ ОСТАВИТЬ, УЛУЧШИТЬ
- **Назначение:** Просмотр рекомендаций к покупке/продаже
- **Что показывать:**
  - Список рекомендаций с понятными карточками
  - Кнопка "Купить" / "Продать" (большая и заметная)
  - Фильтры: только покупки, только продажи, по уверенности
  - Информация: цена, прогноз, уверенность (простой процент)
- **Упрощения:**
  - Убрать технические детали (score, agreement, stage)
  - Простые индикаторы уверенности (высокая/средняя/низкая)
- **WebSocket:** `recommendation` (новые рекомендации)

#### 4. **TradingRequests (Торговые заявки)** - ✅ ОСТАВИТЬ, УЛУЧШИТЬ
- **Назначение:** Управление заявками на покупку/продажу
- **Что показывать:**
  - Список активных заявок
  - История выполненных заявок
  - Кнопки: "Подтвердить", "Отменить"
  - Статусы: ожидает, выполнена, отменена
- **Упрощения:**
  - Убрать технические детали (confidence, score)
  - Простые статусы с цветами
- **WebSocket:** `trading_request_update`

---

### 🔧 ТЕХНИЧЕСКИЕ страницы (для продвинутых пользователей/админов)

#### 5. **NeuralNetworks (Нейросети)** - ⚠️ ПЕРЕИМЕНОВАТЬ в "Обучение"
- **Назначение:** Управление обучением нейросетей
- **Что показывать:**
  - Статус обучения каждой сети (Ensemble, Meta-Learning, RL)
  - Кнопка "Обучить все сети"
  - Прогресс обучения (простой прогресс-бар)
  - История обучения
- **Упрощения:**
  - Убрать технические детали (epochs, batch size, loss)
  - Простые статусы: "Обучена", "Обучается", "Ошибка"
- **WebSocket:** `training_status_update`, `training_progress`

#### 6. **Strategies (Стратегии)** - ✅ ОСТАВИТЬ
- **Назначение:** Просмотр и управление торговыми стратегиями
- **Что показывать:**
  - Список стратегий (консервативная, умеренная, агрессивная)
  - Распределение капитала по стратегиям
  - Производительность каждой стратегии (простой график)
- **WebSocket:** `trading_stats_update`

#### 7. **Settings (Настройки)** - ✅ ПЕРЕДЕЛАТЬ
- **Назначение:** Настройки системы
- **Разделы:**
  - **Основные:** Режим торговли (бумажный/реальный), начальный капитал
  - **Риск-менеджмент:** Стоп-лоссы, трейлинг-стопы, формула Келли
  - **Уведомления:** Telegram, Email
  - **Продвинутые:** (скрыто по умолчанию, кнопка "Показать технические настройки")
- **WebSocket:** Не требуется (настройки меняются редко)

---

### 🗑️ УДАЛИТЬ или ОБЪЕДИНИТЬ

#### 8. **MetricsMonitoring (Метрики)** - ❌ ОБЪЕДИНИТЬ с Dashboard
- **Проблема:** Дублирует информацию с Dashboard
- **Решение:** Перенести важные метрики на Dashboard, остальное в технический раздел

#### 9. **AdvancedMetrics (Продвинутые метрики)** - ❌ ПЕРЕМЕСТИТЬ в Settings → Продвинутые
- **Проблема:** Слишком технично для обычного пользователя
- **Решение:** Скрыть в настройках, доступно только продвинутым пользователям

#### 10. **InstrumentStats (Статистика инструментов)** - ❌ ПЕРЕМЕСТИТЬ в Portfolio → Детали инструмента
- **Проблема:** Отдельная страница для информации, которая должна быть в портфеле
- **Решение:** Показывать статистику при клике на инструмент в портфеле

#### 11. **TradingModeManager (Режимы торговли)** - ❌ ОБЪЕДИНИТЬ с Settings
- **Проблема:** Это настройка, не отдельная страница
- **Решение:** Перенести в Settings → Основные

#### 12. **TrainingDebug (Отладка обучения)** - ❌ УДАЛИТЬ или СКРЫТЬ
- **Проблема:** Техническая страница для разработчиков
- **Решение:** Удалить или скрыть за флагом разработчика

#### 13. **StockDetail (Детали акции)** - ✅ ОСТАВИТЬ как модальное окно
- **Назначение:** Детальная информация об инструменте
- **Решение:** Открывать как модальное окно из Portfolio/Recommendations

## 🔌 Анализ WebSocket реализации

### ✅ ОСТАВИТЬ (используются на пользовательских страницах)

1. **`trading_stats_update`** - ✅ КРИТИЧНО
   - Используется: Dashboard, Portfolio
   - Что передает: стоимость портфеля, прибыль, win rate
   - Статус: Работает, оставить как есть

2. **`training_status_update`** - ✅ КРИТИЧНО
   - Используется: Dashboard (индикатор обучения)
   - Что передает: статус обучения всех сетей
   - Статус: Работает, но нужно упростить для пользователя
   - **Улучшение:** Показывать только "Обучение..." / "Готово"

3. **`recommendation`** - ✅ КРИТИЧНО
   - Используется: Recommendations, Dashboard
   - Что передает: новые рекомендации
   - Статус: Работает, оставить как есть

4. **`trading_request_update`** - ✅ ВАЖНО
   - Используется: TradingRequests
   - Что передает: обновления заявок
   - Статус: Работает, оставить как есть

5. **`portfolio_updates`** - ✅ ВАЖНО
   - Используется: Portfolio
   - Что передает: обновления позиций
   - Статус: Работает, оставить как есть

6. **`alerts`** - ✅ ВАЖНО
   - Используется: Все страницы (NotificationPanel)
   - Что передает: уведомления о важных событиях
   - Статус: Работает, оставить как есть

### ⚠️ УПРОСТИТЬ (слишком технические)

7. **`system_status_update`** - ⚠️ УПРОСТИТЬ
   - Используется: Dashboard (скрыто), технические страницы
   - Что передает: статус нейросетей, WebSocket, БД
   - **Улучшение:** Показывать только общий статус ("Система работает" / "Ошибка")

8. **`performance_metrics_update`** - ⚠️ СКРЫТЬ
   - Используется: Технические страницы
   - Что передает: CPU, память, производительность

9. **`cache_status_update`** - ⚠️ СКРЫТЬ
   - Используется: Технические страницы
   - Что передает: статус кеша
   - **Улучшение:** Показывать только в техническом разделе

10. **`training_progress`** - ⚠️ УПРОСТИТЬ
    - Используется: NeuralNetworks (техническая страница)
    - Что передает: детальный прогресс обучения
    - **Улучшение:** Оставить только для технической страницы, на Dashboard показывать только индикатор

### ❌ УДАЛИТЬ или ОБЪЕДИНИТЬ

11. **`neural_network_status`** - ❌ ОБЪЕДИНИТЬ с `training_status_update`
    - Дублирует информацию из `training_status_update`
    - **Решение:** Использовать только `training_status_update`

12. **`system_resources_update`** - ❌ СКРЫТЬ
    - Используется: Технические страницы
    - **Решение:** Показывать только в техническом разделе

13. **`batch_training_*`** - ❌ ОБЪЕДИНИТЬ с `training_status_update`
    - Дублирует информацию
