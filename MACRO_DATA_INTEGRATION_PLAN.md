# План реализации интеграции макроэкономических данных

## 📋 Обзор

Интеграция макроэкономических данных для улучшения долгосрочных предсказаний нейросетей на 10-15%. Макроиндикаторы будут использоваться как дополнительные фичи для обучения и предсказания.

## 🎯 Цели

1. **Сбор макроэкономических данных:**
   - Инфляция (CPI, месячная и годовая)
   - Ставки ЦБ РФ (ключевая ставка, ставка рефинансирования)
   - ВВП (квартальные и годовые данные)
   - Безработица (месячные данные)
   - Индексы настроений инвесторов (VIX-подобные индексы для российского рынка)

2. **Интеграция в систему:**
   - Хранение данных в БД через модель `MacroIndicator`
   - Добавление макро-фичей в `OptimizedDataService`
   - Автоматическое обновление данных через `SchedulerService`
   - Использование макро-фичей в обучении и предсказании нейросетей

3. **Ожидаемый эффект:**
   - Улучшение долгосрочных предсказаний на 10-15%
   - Более точная оценка рыночных трендов
   - Учет макроэкономического контекста в решениях

## 📊 Источники данных

### 1. Центральный банк РФ (CBR)
- **API:** https://www.cbr.ru/development/SXML/
- **Данные:**
  - Ключевая ставка (ежедневно)
  - Ставка рефинансирования (ежедневно)
  - Инфляция (ежемесячно)
  - Валютные курсы (ежедневно)

### 2. Росстат (Federal State Statistics Service)
- **API:** https://www.fedstat.ru/opendata/
- **Данные:**
  - ВВП (квартально)
  - Безработица (ежемесячно)
  - Инфляция (ежемесячно)
  - Промышленное производство (ежемесячно)

### 3. Московская биржа (MOEX)
- **API:** https://www.moex.com/a2193
- **Данные:**
  - Индекс волатильности (RVI)
  - Индексы настроений (если доступны)

### 4. Альтернативные источники (fallback)
- **Investing.com** (парсинг, если API недоступен)
- **Trading Economics API** (платный, но надежный)
- **Alpha Vantage** (для международных индексов)

## 🏗️ Архитектура решения

### 1. Модель MacroIndicator (`server/src/models/MacroIndicator.js`)

```javascript
{
  id: INTEGER (PK),
  indicatorType: ENUM('inflation', 'interest_rate', 'gdp', 'unemployment', 'sentiment', 'other'),
  source: STRING(50), // 'cbr', 'rosstat', 'moex', 'investing', etc.
  value: FLOAT, // Значение индикатора
  period: DATE, // Период данных (дата публикации)
  periodType: ENUM('daily', 'monthly', 'quarterly', 'yearly'),
  unit: STRING(20), // 'percent', 'absolute', 'index', etc.
  metadata: JSON, // Дополнительные метаданные (изменение, прогноз и т.д.)
  createdAt: DATE,
  updatedAt: DATE
}
```

**Индексы:**
- `(indicatorType, period, source)` - уникальный индекс для предотвращения дубликатов
- `period` - индекс для быстрого поиска по датам

### 2. Сервис MacroDataService (`server/src/services/MacroDataService.js`)

**Основные методы:**

#### 2.1. Инициализация и настройки
- `initialize()` - инициализация сервиса
- `loadSettings()` - загрузка настроек из Settings
- Настройки:
  - `macro_data_update_interval` - интервал обновления (cron)
  - `macro_data_sources` - список активных источников
  - `macro_data_cache_ttl_hours` - TTL кеша

#### 2.2. Получение данных из внешних источников
- `fetchCbrData()` - получение данных от ЦБ РФ
- `fetchRosstatData()` - получение данных от Росстата
- `fetchMoexData()` - получение данных от Мосбиржи
- `fetchInvestingData()` - парсинг данных с Investing.com (fallback)

#### 2.3. Обработка и нормализация данных
- `normalizeIndicator(indicatorType, rawData)` - нормализация данных из разных источников
- `validateData(indicator)` - валидация полученных данных
- `calculateDerivedIndicators()` - расчет производных индикаторов (изменения, тренды)

#### 2.4. Сохранение данных
- `saveIndicator(indicator)` - сохранение индикатора в БД
- `updateIndicator(id, data)` - обновление существующего индикатора
- `bulkSaveIndicators(indicators)` - массовое сохранение

#### 2.5. Получение данных для использования
- `getIndicator(indicatorType, date)` - получение индикатора на конкретную дату
- `getIndicatorsForPeriod(indicatorType, startDate, endDate)` - получение индикаторов за период
- `getLatestIndicators()` - получение последних значений всех индикаторов
- `getMacroFeatures(date)` - получение макро-фичей для конкретной даты (для нейросетей)

#### 2.6. Кеширование
- Кеш в памяти для часто запрашиваемых данных
- TTL кеша настраивается через Settings

### 3. Интеграция в OptimizedDataService

**Изменения в `createFeatureVector()`:**

```javascript
// Добавить метод getMacroFeatures()
async getMacroFeatures(date) {
    try {
        const macroData = await MacroDataService.getMacroFeatures(date);
        
        return [
            macroData.inflation || 0,           // Инфляция (годовая, %)
            macroData.inflationChange || 0,     // Изменение инфляции (месяц к месяцу)
            macroData.interestRate || 0,         // Ключевая ставка ЦБ (%)
            macroData.interestRateChange || 0,   // Изменение ставки
            macroData.gdpGrowth || 0,           // Рост ВВП (год к году, %)
            macroData.unemployment || 0,        // Безработица (%)
            macroData.sentimentIndex || 0.5,    // Индекс настроений (0-1)
            macroData.volatilityIndex || 0.5    // Индекс волатильности (0-1)
        ];
    } catch (error) {
        console.warn('⚠️ Failed to get macro features:', error.message);
        // Возвращаем нулевые значения при ошибке
        return new Array(8).fill(0);
    }
}
```

## 🔧 Технические детали

### Формат макро-фичей для нейросетей

```javascript
[
    inflation,              // Инфляция (годовая, %) - нормализовано [0, 1]
    inflationChange,        // Изменение инфляции (месяц к месяцу, %) - нормализовано [-1, 1]
    interestRate,           // Ключевая ставка ЦБ (%) - нормализовано [0, 1]
    interestRateChange,     // Изменение ставки (%) - нормализовано [-1, 1]
    gdpGrowth,             // Рост ВВП (год к году, %) - нормализовано [-1, 1]
    unemployment,          // Безработица (%) - нормализовано [0, 1]
    sentimentIndex,        // Индекс настроений (0-1)
    volatilityIndex        // Индекс волатильности (0-1)
]
```

### Нормализация данных

- **Инфляция:** Нормализация в диапазон [0, 1] на основе исторических данных (0% = 0, 20% = 1)
- **Ставки:** Нормализация в диапазон [0, 1] (0% = 0, 25% = 1)
- **ВВП:** Нормализация в диапазон [-1, 1] (-10% = -1, +10% = 1)
- **Безработица:** Нормализация в диапазон [0, 1] (0% = 0, 20% = 1)
- **Индексы настроений:** Уже в диапазоне [0, 1]

### Обработка отсутствующих данных

- Если данные отсутствуют на конкретную дату, использовать последние доступные данные
- Если данных нет вообще, возвращать нулевые значения (или средние исторические)
- Логировать предупреждения при отсутствии данных

### Кеширование

- Кеш в памяти для последних 30 дней данных
- TTL кеша: 1 час для ежедневных данных, 24 часа для месячных/квартальных
- Автоматическая очистка устаревших данных из кеша

## ⚠️ Риски и ограничения

### Риски:

1. **Доступность API:**
   - API ЦБ РФ, Росстата могут быть недоступны
   - Rate limiting на внешних API
   - Изменение формата данных источниками

2. **Качество данных:**
   - Задержки в публикации данных (особенно ВВП)
   - Пересмотр исторических данных
   - Ошибки в данных источников

3. **Производительность:**
   - Парсинг HTML может быть медленным
   - Большой объем данных для хранения

### Ограничения:

1. **Частота обновления:**
   - Некоторые данные обновляются редко (ВВП - квартально)
   - Необходимо учитывать задержки публикации

2. **Исторические данные:**
   - Ограниченная история доступных данных
   - Необходимость заполнения пробелов

3. **Международные данные:**
   - Фокус на российских данных
   - Международные индексы могут быть недоступны
